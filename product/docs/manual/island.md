# 人口と資源

施設の「規模」は働ける人数、人口は実際に住んでいる人数です。**施設を増やすことと、人口を増やすことは別です。**

## 人口

人は村・町・都市・首都に住みます。農場や人のいるマスの隣の空いた平地には新しい村が生まれ、人が増えると町、都市へと呼び名が変わります。

- 誘致活動をしたターンは、人口が増えやすくなります
- 一つのマスに住める人数には上限があります。秘書の技能などで上限を上げられます
- 首都はほかの集落より多くの人が住めます。首都地下に地底都市を置くと、さらに増やせます
- 首都には名前をつけられます（[海と船](/manual/sea)の「船と首都の名前」と同じ操作です）

## 働き手と生産

住民はまず農場で働き、残った人が工場と採掘場で働きます。

| 職場 | 作るもの |
|---|---|
| 農場 | 小麦 |
| 工場 | 工業品 |
| 採掘場 | 鉱物 |
| 海底油田 | 石油（働き手はいりません） |

施設を建てても、働く人が足りなければ規模の分だけは作れません。逆に人が多くても、職場が足りなければ働けない人が出ます。

## 食料

住民は5人で小麦1トン分を毎ターン食べます。食料には小麦・魚・怪獣肉があり、怪獣肉は同じ重さで2倍お腹がふくれます。

食料が足りなくなると飢饉になり、人口が減ります。暴動で施設を失うこともあります。災害で農場を失ってもすぐには困らないよう、何ターン分か残しておくと安心です。

## 売却方針

工場と採掘場は、お金ではなく資源を作ります。「収支と資源」の「資源・売却方針」で、資源ごとに残す量を決めると、それを超えた分がターン更新のときに売れます。

- **小麦は全部売る設定にできません。** 住民が食べる分は残ります
- 石油は船や火力発電所の燃料にもなります。売りすぎに気を付けてください
- 売れるのはまとまった量ごとで、半端な分は残ります

## 蓄えの上限

資金・食料・資源には持てる上限があります。今の上限は画面のゲージで確かめられます。

上限を超えた分は、売れるものは売られ、残りは捨てられます。中央銀行・中央穀倉、秘書の技能、アイテムで上限を増やせます。

捨てられてしまった分は「エコポ」として島に貯まり、貯まると自動で輝石（Pd）に交換されます。残高は「収支と資源」の「島のあらまし」に出ます。

## 電力

風力発電所や火力発電所で電気を作り、ピザ屋がその電気と食料を使って売上を出します。使い切れなかった電気は、コンデンサがあれば次のターンへ持ち越せます。電気そのものは売れません。

火力発電所は石油を使い、足りない分は鉱物で補います。風力は燃料がいりませんが、発電量はターンごとに変わります。

## 輝石（Pd）

輝石は、輝石で建てるコマンドなどに使う特別な通貨です。島の資金や、地底で使う輝石の欠片（G）とは別で、ほかのプレイヤーへは渡せません。

毎日のログインや、決まったデイリーを達成すると受け取れます。届いたときは画面に知らせが出ます。

## 運営からの配布

運営からの配布があると、開発画面に配布倉庫への入口が出ます。蓄えに入る分だけ受け取れ、入りきらない分は倉庫に残ります。

## 収支が合わないときは

1. 人口と農場の規模は釣り合っているか
2. 工場・採掘場で働く人は残っているか
3. 売却方針で資源を売る設定になっているか
4. 蓄えが上限に届いていないか

建てたばかりの施設は、その更新で終わった生産にはさかのぼって加わりません。次の更新の結果を見てください。
