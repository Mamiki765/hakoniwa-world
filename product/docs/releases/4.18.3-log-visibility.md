## 採用例外と既存経路

- 海底都市の設備維持不足は本人へ、施設数にかかわらず島・ターンごとに一文だけ表示する。文面は `海底都市の設備維持に必要な工業品または鉱物が不足しています！`。人口計算・既存イベント保存は変更しない。
- SPP の条件を満たす故意 HP1 化は既存カルマ計算へ30を渡す。表示は保存済み `crime_points` を使うため、過去の20を30へ書き換えない。
- 船へのミサイル命中・撃沈は既存 `missile.impact` の公開経路を維持する。残HPは所有者の詳細表示に限定する。
- 地上アイテム売却は完了画面だけで確認し、ターンログへ追加しない。
- 森の個別抑止、資金繰り、原作無記録の実況は復活させない。

## Ruleset と検証範囲

使用済みv35と既存 migration は変更しない。v36はv35から key/version と SPP カルマ30だけを変更する。forward migration は既存の World lock、未解決Turn拒否、transaction、同一definitionへの再紐付けを再利用し、過去Turn・人口・資産・既存カルマを変更しない。fresh migration が v35を通過できるよう、v35の完全一致を検査する historical publication 経路を追加する。

今回の確認は source / 差分 / 秘匿字段 / 保存イベント帰属 / 設定継承 / migration 経路の静的確認と `git diff --check` のみ。既存テストの旧期待値を置換し、ケース・assertionは追加しない。テスト・migration・CI・本番操作は実行しない。実行時の認可・集約・アップグレード確認は未実施で、独立レビューは別担当へ引き渡す。
