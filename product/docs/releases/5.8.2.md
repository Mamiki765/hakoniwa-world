# 5.8.2 ルールセット設定のJSON解読をモデル単位で再利用

application **5.8.2 / Ruleset v41**。5.8.1（main `1b3d988332a4b52caf416a3704915237f3ed465c`）に続く、PR [#340](https://github.com/Mamiki765/hakoniwa-world/pull/340) の単独パッチ。元コミット `05d1fd619505219910863b7a2d19136016edb629` を保持して `release/5.8.2` に統合する。本書はリリース準備の範囲を示し、本番への適用完了を意味しない。

## 変更

- `RulesetVersion::settings` の同じJSON文字列の解読結果をモデル内で再利用し、ターン中の反復解読を減らす。設定の代入・生値の再読込で文字列が変わると解読し直す。書き込みは従来と同じ `asJson` を使う。
- 設定の往復、代入、生値差し替え、nullを単体テストで確認する。既存のターン・Ruleset回帰テストと最終HEADのQuality CIを検証の基準にする。
- ゲームの処理順・乱数・計算式・永続化内容・Ruleset snapshotは変更しない。Rulesetの世代更新、migration、依存更新はない。PR #338 は含めない。
