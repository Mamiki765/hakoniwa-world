# ver 2.4.0-beta announcement

ver 2.4.0-betaのdeployと動作確認が完了した後、repository convention上player-facing announcementが必要な場合に限り、既存のお知らせ管理画面から次の内容を1件作成する。migration、seeder、deploy scriptから自動作成・上書きしない。同じrelease announcementがすでに存在する場合は重複作成しない。

## Title

```text
ver 2.4.0-beta
```

## Body

```text
・長期間操作のない島が「放置」状態になる休止機能を追加しました。休止中は通常の生産・消費・人口変化・開発実行が停止し、島には冬が訪れます。
・首都から距離2以内は、休止中のみミサイル・災害・怪獣・領土変化から保護されます。保護範囲の外側は通常どおり影響を受けます。
・プロフィールの「危険な操作」から、1〜7日間の手動休止を設定できるようになりました。手動休止は指定期間が終わるまで解除できません。
・自動休止中は、通常commandを開発予定へ登録すると次のofficial Turn開始時に活動を再開します。
・新しく登録した島は、最初のofficial Turnで通常の開発を行わなかった場合、休止状態へ入ります。
・長期間そのまま放置された島は自動的に破棄されます。
・休止開始・再開、災害被害、保護されたミサイルなど、島ログの表示を改善しました。
```

作成後はpublic lobbyの最新お知らせと詳細でtitle、改行、本文を確認する。
