# 地底の冒険

地底は、秘書を育てて魔物と戦う冒険の場所です。地上のターン更新を待たずに、自分のペースで遊べます。

## 始め方

秘書に名前を付けたら「地底」を開き、案内に沿って導入を進めます。途中で秘書の成長方針を選ぶと、探索やお店が使えるようになります。

## 冒険の流れ

> 探索する → 宿や銀行で備える → 能力・スキル・装備を整える → もう少し強い相手へ

最初は「周囲の探索」から浅い洞窟へ向かいます。戦闘は、あらかじめ決めた装備・スキル・作戦で自動に進みます。ログを読む速さで結果は変わりません。

試練を越えると、新しい探索先が開いていきます。

## 勝ったとき・負けたとき

| 結果 | どうなるか |
|---|---|
| 勝利 | 経験値と輝石の欠片（G）を得ます。装備が手に入ることもあります。HPは減ったまま次へ持ち越します |
| 敗北 | 手持ちのGが半分になります。銀行の預金と持っている装備は減りません。HPは回復します |
| 時間切れ | 長く戦っても決着がつかないと撤退になります。報酬は少しだけです |

MPは戦闘のたびに全回復しますが、HPは勝っても回復しません。続けて戦うときは残りHPを見てください。

## 町の施設

| 場所 | できること |
|---|---|
| 宿 | 手持ちのGでHPを全回復します |
| 銀行 | Gを預けます。預けたGは負けても減りません |
| 武具屋 | 手持ちのGで装備を買います。試練を越えると品ぞろえが増えます |
| 宝物庫 | 手に入れた装備を保管し、比べて付け替えます。いらない装備を売れます |
| 案内人の部屋 | 成長方針・能力・スキルの振り直し（再振り）ができます |

宿・武具屋・再振りの支払いは手持ちのGからです。銀行にあっても使えないので、先に引き出してください。

## 試練

試練は10連戦の挑戦です。戦闘の合間に「先へ進む」か「帰還する」かを選べます。

- 途中で帰還しても、それまでに勝った分の報酬は持ち帰れます
- 負けたり撤退したりすると、その挑戦は終わります
- 挑戦中は宿と再振りが使えません
- 初めて最後まで勝つと、スキルのポイント、新しい探索先、首都地下の設備枠などが手に入ります

## 育てる

| 表示 | 意味 |
|---|---|
| 戦闘Lv・EXP | 戦って上がる秘書の強さ |
| STP | 生命・武力・技巧・精神・敏捷の五つの能力へ配るポイント |
| SP | スキルを覚えるポイント。レベルではなく、試練などで増えます |
| IL | 装備そのもののレベル。秘書のレベルとは別です |

- 覚えたスキルは、**使用枠に入れないと戦闘で使いません**
- 作戦（AI）は「条件」と「行動」を上から順に並べたものです。最初は決まった作戦で戦えます。自分で組むときは、上の行ほど優先されることに気を付けてください
- 試練を越えると覚醒が使えるようになります。戦闘中に一度、秘書が大きく強くなります
- 装備は武器・防具・アクセサリーなどの枠ごとに一つずつ。持っているだけでは強くなりません

スキルの効果、装備の数値は、それぞれの画面の説明がいちばん正確です。

## 仲間と探索する

ふだんの探索では、ほかのプレイヤーが公開している秘書を助っ人に借りられます。借りた秘書の強さは、自分の秘書に合わせて調整されます。試練は一人で挑みます。

## スキップチケット

同じ探索先で何度も勝つと、スキップチケットで戦闘を飛ばせるようになります。チケットは毎日のログインや、貸し出した秘書へのお礼で届きます。

## 地上を強くする首都地下

試練で開いた設備枠には、地底都市・地底農場・地底工場・地底ミサイル基地を置けます。**建てるのは地上の開発計画で、島の資金とターンを使います。** 地底のGでは買えません。種類と費用は[施設の索引](/manual/facilities)へ。

## 困ったとき

- 技を使わない → 使用枠に入れたか、MPは足りるか、作戦の上の行がいつも選ばれていないか
- 銀行にGがあるのに買えない → 手持ちに引き出す
- 勝ったのに装備が出ない → 装備は毎回出るわけではありません。宝物庫がいっぱいでも受け取れません
