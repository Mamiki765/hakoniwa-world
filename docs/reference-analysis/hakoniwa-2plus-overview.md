## 文字コードと改行

バイト列を厳密に往復変換して候補を確認した。日本語を含むファイルは CP932 と Shift_JIS の双方で同一バイトへ戻るため、この資料だけでは両者を完全には区別できない。ただし、HTML出力が `charset=Shift_JIS` を明示し、文字列切り詰めもShift_JIS系の2バイト先頭範囲を直接判定しているため、実行時の意図は **Shift_JIS系（CP932互換範囲を含む）** と確定できる（`template.c:3-25`, `Util::cutColumn`, `util.c:67-97`）。

## 調査順序

指定順を基準に、`Makefile` → `main.c` → 全ヘッダー → `value.c`/`config.cgi` → `map.c` → `new_island.c` → `owner.c` → `turn.c` → `command.c` → `monster.c` と読んだ。その後、次の理由で補助ファイルを追跡した。

- 永続化形式を確定するため `hako_io.c` と `info.c` を追加。
- 排他制御、乱数、文字処理を確定するため `util.c` を追加。
- バックアップと復旧を確定するため `mentenance.c` を追加。
- CGI出力経路を確定するため `template.c`, `sight.c`, `toppage.c`, `rename.c` を追加。

`hakow.js` はC側が出力するJavaScriptデータの受け手であり、今回の中心であるゲーム挙動・保存構造の確定にはC側だけで足りるため、ファイル同一性と文字コードの確認に留めた。現代版参考実装は読んでいない。

## 主要な確定事項

1. `.c` 拡張子だが、ビルドは `g++` を使う単一CGIである（`Makefile:1-19`）。
2. 全国家が一つの `Map::land` 配列と一つの `map.cgi` を共有する（`map.c:3,13-47`; `hako_io.c:116-152`）。
3. 世界は設定値 `worldSize=60` の固定正方形で、`y * worldSize + x` の行優先配列である（`config.cgi:43-44`; `Map::getLand`, `map.c:89-97`）。
4. 1セルは4桁ではなく、`kind` 1桁 + `param` 2桁 + `owner` 2桁の **5桁16進数** である（`Land::output`, `map.c:1233-1237`）。
5. 新規国家の位置は自動探索ではなく、CGIから渡された中心座標を使用する（`HakoIO::cgiInput`, `hako_io.c:429-433`; `NewIsland::main`, `new_island.c:50-75`）。
6. ターンは国境感化、収支、国家ごとの先頭コマンド、全セル処理、難民、全体災害、再集計、消滅・順位更新、保存、バックアップの順である（`Turn::main`, `turn.c:9-148`）。
7. 首都という地形・不変施設・最低人口保証は存在しない。中心座標は表示・攻撃目標・難民受入れの中心として使われ、変更コマンドもある（`Com::exec`, `command.c:616-620`; `Map::getBoatPeople`, `map.c:1076-1105`）。
8. 地形、施設、コマンド、費用、災害判定の多くは列挙定数、配列、`switch` に直書きされている（`map.h:136-168`; `command.c:5-35,205-621`; `Map::process`, `map.c:264-739`）。
