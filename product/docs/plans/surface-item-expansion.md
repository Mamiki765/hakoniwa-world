# 地上アイテム拡張：Relic・合成・育成アイデア帳

更新：2026-09-28。分類：**Ownerの構想・採用方向と未決事項**。未実装の設計メモであり、現在のRulesetへ自動追加しない。

この文書は、今後増える地上アイテム案を忘れないための常設メモ。4.6地下装備の一時開始資料とは別で、地上アイテム案を継続して追記する。実装時は現行code、Ruleset、Open gateを再確認し、このメモだけをcurrent runtime contractにしない。

## 1. Relic

- 地上アイテムの上位rarityとして**Relic（レリック）**を使う。Artifactより上。
- 固定売値は**6,000億**。
- Relicは将来的にドキドキチケットから約1%程度で出る案があるが、**主な入手は合成**にする方向。
- 一部の例外Relicはタグ/分類でチケット排出対象外にする。合成限定・隠し系を想定。
- 2026-09-28時点では、ドキドキチケットから排出する具体的Relicはまだ考えない。まずRegular / HQ / Artifact以下の地上アイテムを増やす。
- 現行のドキドキチケット排出率やRelic排出率を、この構想だけを理由に今すぐ変更しない。

## 2. 合成の目的

合成は主に次の二つを狙う。

1. **ダブった地上アイテムの消化・育成**
2. **複数の既存効果を、作者定義の固定レシピで上位rarityへ圧縮するやり込み**

「任意の効果AとBを自由にmergeする汎用効果合成」は作らない方向。効果圧縮も**固定レシピの拡張**として扱う。

将来、複数効果をまとめたRelicを作る場合、素材側の効果を最大限引き継ぐには、弓や衣服のように素材自身を同系統アイテムで育てておくことが重要になる構想。完成品だけ拾って即最大性能になるとは限らない。

ただし、すべての固定レシピに素材Lv継承を要求するわけではない。レシピごとに決める。

## 3. 同系統アイテムの修行・Lv育成

弓やスーツは上位rarityが強く、下位rankが入手後に空気になりやすい。そのため、下位rankや同系統のダブりを上位品へ食わせ、Lvを上げる仕組みを検討する。

例として考えている方向：

- Artifactの任意の弓を育てるため、同系統のHQ / Regular弓を素材にする。
- 1rank下をどの程度の確定成長にするか、2rank下を「複数枚まとめて昇格素材にする」「低確率で1rank上へ変える」「rarityごとの固定経験値にする」等は未決。
- 同種/同系列の育成量を単純な+1/+2にするか、経験値方式にするかも未決。
- 将来の合算Relicでは、素材弓・素材衣服の育成度が継承効果量へ影響する案を残す。

目的は「下位レアを引いたら完全なハズレ」を減らし、Regular → HQ → Artifact → Relicへ長期的な価値を繋ぐこと。

## 4. 固定レシピと効果圧縮

効果圧縮は固定レシピで定義する。

例：

- 農場+20%系アイテム + 工場+15%系アイテム
- → 将来の固定レシピRelicとして、農場/工場の複合効果を持つ
- 基本イメージは低い側に揃えて農場+15% / 工場+15%のように圧縮する案

ただし将来、素材Lv/育成度を継承率へ使う場合は、最大値を引き継ぐために素材を先に育てる必要がある。

この数値・継承式・対象カテゴリはまだ未決。固定レシピごとに決める。

## 5. 夢魔の三紋章 / 夢魔の紋章

### 素材

- 愛の紋章
- 双子星の紋章
- 三日月の紋章

三つとも**Lv1固定のArtifact**。それぞれ自体がレアなアイテムであり、三つ揃えること自体を入手難度とする。弓のような素材育成・Lv継承は要求しない。

「夢魔の三紋章」は三つをまとめる概念上のタグ/グループ名として扱う構想。実装keyやUI表記を今ここで固定しない。

### 固定レシピ

```text
愛の紋章
+ 双子星の紋章
+ 三日月の紋章
= 夢魔の紋章
```

### 夢魔の紋章

- rarity：Relic
- Lv：**1固定**
- 入手：**合成限定の隠しアイテム**。ドキドキチケット等の通常排出から除外する方向。
- 効果：**自然回復と誘致活動での人口増加が2倍**
- フレーバー：
  - 「人間よ、快楽だけを貪る獣に帰れ。もう何も暗い事を考えなくて良い様に。」
- 三つのレア素材を揃えることが難度なので、完成後の素材育成条件は付けない。
- 現段階ではプレイヤーへ実際に入手させることを急がない。三素材の存在から「何かある」と示唆すること自体を楽しみにする。
- 具体的な公開時期、レシピの開示方法、合成UIで見せるかどうかは未決。

## 6. 同種圧縮

同じアイテム同士を重ね、倉庫を圧縮する用途も合成へ含める。

### チケット

```text
わくわくチケット LvA
+ わくわくチケット LvB
= わくわくチケット Lv(A+B)
```

- Lv合算を主用途にする。
- 一部アイテムだけ通常max_levelを超えて合成できる仕組みも候補。
- わくわく / ドキドキチケット、お守り等の圧縮に使う案。
- どのアイテムが上限突破可能か、合成上限、UI、使用時の一括処理は未決。

現行実装ではチケット使用時にitem levelを抽選回数として扱う経路があるが、現行Catalog上のチケットmax_levelは1。将来実装では既存の決済・倉庫容量・retry契約を確認し、単にmax_levelだけを変えて済むと決めつけない。

## 7. 実装前に決めること

- 合成UIの置き場所と解禁条件
- 合成時のtransaction / retry / idempotency
- 素材が装備中・取引中・escrow中の場合の扱い
- 同系統育成の対象関係（同一key / 同カテゴリ / 定義済み系譜）
- 1rank下・2rank下の育成量
- 素材Lvを固定レシピ完成品へどう継承するか
- 通常max_levelと合成上限突破を同じ値で持つか分離するか
- Relicのドキドキチケット排出率・具体的な排出対象（今は決めない）
- 合成限定タグ/排出除外の表現方法
- 合成結果の売値・tradable/npc_tradable
- Ruleset versioningと既存アイテムinstanceの保持

2026-09-28のmain確認では、地上CatalogにRelic rarityと固定売値6000億は既に存在する。三紋章もArtifact / Lv1として存在する。現行ドキドキチケットはHQ / Artifactのみで、Relic排出枠はまだない。

この確認メモは将来の実装開始時に再確認する。数値を永久固定するテストの根拠にしない。
