# 5.1.2

application version は **5.1.2**。Ruleset は v36 を維持し、追加 migration はない。5.1.1 の main を基点に、次の変更を統合する。版定義の更新はこの release で一度だけ行う。

- #255: 建設ログと収支明細の施設名を対象 World の Ruleset 定義から解決する。保存済み名称 snapshot を優先し、World 間の名称分離と cache を維持する。
- #256（先行 merge 済み）: 施設建設の数量処理を共通化する。
- #257: 交易の非食料配送で、容量超過分を売却方針によらず換金可能な範囲で売却し、残りだけを破棄する。
- #258: 開発計画の位置詰め直しを API と Turn で共通化する。
- #259: 海底基地・海底都市・海底消防署の新規建設は自国陸地から3ヘックス以内とする。距離外の将来計画も予約保存でき、予測と実行で距離を検証する。失敗する予約から後続予測へ施設・領有を伝播させず、既設施設を変更しない。

#188 は対象外。Owner 指示により #255・#259 の後続 Codex review を release の待機条件にせず、後から届く指摘の修正は 5.1.3 へ回す。
