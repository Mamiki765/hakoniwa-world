# 4.14.3 秘書の肩書き表示・実績画面

application **4.14.3**。Rulesetはv33を維持する。PR204・PR202がマージ済みのmain `c1d0df62d8a4a902c3375db62f39dc90bab8ce8c` を基点とする。

秘書画面の左上の「秘書」を、装備中の肩書きへ置き換える。肩書きが未装備なら「秘書」を表示し、大きな秘書名はそのままにする。メイン画面の基本情報に追加していた肩書き欄は削除する。
