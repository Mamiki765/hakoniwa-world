# 3.10.0 スキル・戦闘バランス再調整

2026-09-13。基準mainは `87452d06cd54e07dfde33f90e4174e5d37197045`、再調整前候補は `679a2f7bc33538177e554ab44092b5b1ab7194f5`。本書と[集計JSON](3.10.0-balance/readjustment-results.json)は `78461b666a017b6b8a20c536be1402e0037ec3aa` 時点の測定記録。[王国のPT再評価](3.10.0-kingdom-party-reevaluation.md)で通常2倍・強敵2.5倍へ更新したため、本書の王国一律2.5倍・solo200/280は現在値ではない。木人・係数・MP・技巧は維持する。[最初の候補の比較](3.10.0-underground-rebuild.md)も当時の条件を保存した記録である。技の名前・倍率・数を固定するものではない。

## 結果と変更範囲

Lv90・100 SP・標準構成の木人100roundでは、戦技100%、護身82.61%、祝福78.85%。護身は標準例をSTP体力60%・武力40%とし、武力極振りで88.90%まで伸びる。体力極振りから武力へ配分を移す途中で火力が落ちる逆転を解消した。

変更は護身4攻撃技の係数・威力、闘志の追加威力、鏡陣の反撃と既定AI、会心へ渡す主能力、ワイバーンと王国の敵側数値に限定した。戦技・祝福の技の威力、SP、CT、MP、5枠、30技の構成、成長値は再調整前候補を維持する。地下combat v5・skill tree v2・地上Ruleset v25のまま、追加migrationは作らない。

## 条件を混ぜない

- 通常の役割比較は100round。200roundはMP耐久だけに使用する。
- 木人はHP10億、両防御Lv×5、無行動、被害0。以前の「防御し続ける木人」と異なる。旧版も同じ新しい木人で測定し直した。
- 合成装備は5部位uncommon、Lv30/60/90に対応するIL30/60/90。生成seed3100〜3104、戦闘seed31000〜31031。生成tier名はobsidian_cavernに固定しており、Lv30で魔窟に入れるという意味ではない。
- 標準STPは戦技が武力80%・体力20%、祝福が精神80%・体力20%、護身が体力60%・武力40%。護身の割合は検証の代表例で、Owner固定値やruntimeの自動配分ではない。
- 木人は覚醒による回復・攻撃を必要としない条件。被弾測定は覚醒なし。実戦snapshot再現は保存された開始HP・覚醒状態を保持する。
- 32seedは同じ能力・装備での戦闘乱数比較であり、32人の独立したプレイヤーや32種類の装備の平均ではない。

## 護身の配分と反撃

盾撃・闘志破砕・不屈反攻・震天衝は体力40%・武力60%を参照。potencyはそれぞれ17850・22750・35700・11550 bps。不屈反攻は闘志0でも使用でき、闘志は1段200 bps・最大5段の追加威力となる。闘志破砕も同じ追加量。会心へ渡す主能力は技と同じ体力・武力の合成値。武力だけを基準にして火力が途中で落ちる問題を避ける。

|---:|---:|---:|---:|---:|
| 0% | 100% | 7531 | 435.66 | 78.49% |
| 25% | 75% | 6643 | 449.97 | 81.07% |

| 75% | 25% | 4867 | 477.87 | 86.10% |

旧版でも武力を増やすと総DPRは57.60→65.95→74.56→83.40→91.86と伸びた。技自体は体力寄りだったが、MP不足で通常攻撃が56回入り、武力の影響が大きかった。新候補では技が回り続けるため、同じ役割を保つには技自体にも武力を配分する意味が必要だった。

鏡陣の反撃は `counter_power_bps=300`、体力6・武力4の重み。会心なし。敵1体につき1round1回、同じ敵の多段hitは上限を共有する。防御・障壁で防ぐ条件は維持する。NPCの反撃は既存の全体で1round1回を維持する。

既定AIは敵の予告、またはHP95%以下かつaegisなしで鏡陣を使う。無傷の木人へ防御を貼り直す行動負担をなくし、標準DPSのために盾撃単体を過剰強化することを避けた。同じ戦技成長・装備では、戦技標準555.03に対して盾撃1枠370.64、護身5枠512.30、攻撃混成5枠492.65 DPR。盾撃6 SPだけで専門構成を置き換える結果にはなっていない。

## 祝福のMPとマーシー

通常攻撃ローテーションのMP不足による使用不可はLv30/60/90、標準・攻撃構成とも100roundで0。Lv90標準は終了MP5200、攻撃構成4300。補助200roundも不足0、終了MP6200/5600。初期MPを使い潰すだけの運用にはなっていない。

回復混在はLv90の戦技・護身・祝福3人対固定AoE。ヒーラーはヒール・リジェネレーション・リザレクション・マーシー・マナリカバーの5枠、78 SP。全員のskill/modifier/AIを現在のcatalogで組み直す。敵HP10万、上限100roundなので勝利時は100未満で終わる。これは木人DPSの表ではない。

## 技巧

会心率・会心倍率を増やすのは技巧。相対技巧の分母に使う主能力は物理なら武力、祝福なら精神、体力を使う物理技は体力・武力の合成値。元の `max(武力,精神)` をやめ、無関係な能力を増やしただけで会心が下がる問題を直した。確率・倍率の式そのものは最初の3.10.0候補から維持する。

Lv30/90/484で主能力＋技巧の予算を同じにし、技巧0/30/50%を各256seed・100roundで比較した。装備と他能力を固定し、実際の戦技・祝福攻撃構成を使う。Lv484はLv90の装備・他能力を固定して主能力予算を増やす感度測定であり、実在Lv484秘書の再現ではない。

| 系統・Lv | 技巧割合 | 100round平均総damage | 最大一撃 | 最初10round直接damage p99 |
|---|---:|---:|---:|---:|
| 戦技30 | 0% / 30% / 50% | 22783 / 25131 / 26915 | 1192 / 1352 / 1324 | 2943 / 2933 / 2819 |
| 祝福30 | 0% / 30% / 50% | 24419 / 22576 / 21404 | 1592 / 1808 / 1748 | 3501 / 3412 / 3620 |
| 戦技90 | 0% / 30% / 50% | 63068 / 69841 / 75075 | 6736 / 7704 / 7508 | 9876 / 9031 / 9317 |
| 祝福90 | 0% / 30% / 50% | 56274 / 51625 / 48883 | 5212 / 6152 / 5992 | 9212 / 9523 / 9675 |

祝福は平均低下と大きな一撃・短期上位値の交換が確認できる。100round総damageのp99まで純精神を上回るわけではない。純型の10round平均×112%という閾値の突破頻度も一律には増えない。戦技は出血も技巧で伸びるため総平均が増える一方、直接攻撃の短期平均は落ちる。この構成依存性を記録し、「全攻撃構成で平均が必ず下がる」「あらゆる上位指標が改善する」とは説明しない。

## 実戦データと攻略難度

Ownerの許可で、本番をread-only transactionとして取得した。王国でactual winが40以上ある14 profileについて、50勝付近と直近のsnapshotを優先した。王国514戦のうちsolo280、PT234。別に試練10体目84戦。PTをsolo到達の証拠へ使わない。

候補再現はLv・STP・装備・開始HP・覚醒・private seedを維持し、旧装備技の役割を新しいrank1と既定AIに移す。旧聖光審判はホーリーランスへ置換。SP予算は初期20・試練2到達60・王国100または既得SPの大きい方。旧custom AIを文字列のまま新ルールへ強制適用しない。この再構成自体も比較の差である。
