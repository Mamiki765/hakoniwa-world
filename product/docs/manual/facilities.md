# 施設の索引

建てられる施設の一覧です。費用は1回分で、いまのゲームの設定から表示しています。建てられる場所や条件の細かいところは、開発画面のコマンド欄とマスの詳細がいちばん正確です。

**同じ施設をもう一度建てると増設になるもの**（農場・工場・採掘場・火力発電所・ピザ屋）や、**Lvが上がるもの**（中央銀行・中央穀倉）があります。農場・工場・採掘場は上限まで育てるとランク2になります。

## 他島からの見え方

ミサイル基地・中央銀行・中央穀倉は、他島からは森に見えます。海底基地・海底都市・海底消防署は、他島からは海に見えます。ハリボテは防衛施設に見えます。
