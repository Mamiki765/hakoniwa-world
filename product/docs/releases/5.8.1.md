# 5.8.1 ブーストの帯をTOPだけに表示

application **5.8.1 / Ruleset v41**。5.8.0（main `7c9b4c8`）に続く画面だけの単品修正。migration・Ruleset・API・サーバー処理の変更はない。本書はコードの範囲を示し、本番への適用完了を意味しない。

## プレイヤー向けの変更

- 時間加速・狩場ブーストの帯（予告・開催中）はTOPだけに表示する。5.8.0では島に時間加速、地底に狩場ブーストの帯も出していたが、作業画面では大きすぎるため外した。
- TOPのターン欄の「停止補填中：追加ターンあり（未補填分のみ）」表示は変わらない。

## コード

- `App.vue` から島・地底用の帯（`pageBoosts`）を削除。
- 使われなくなった `BoostBanner.vue` の `compact` 表示と `hakoniwa.css` の `.boost-slot` を削除。
