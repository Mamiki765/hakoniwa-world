# 4.3.0 地底UI再設計

Status: Implemented for review. Base: Forgejo main `531fdd916bb10a676a8a107ffb1a9f1c769ec291`。作業branchはOwner指定の `release/4.3.0`。アプリのmerge・production反映は別判断。提供素材の配信先への配置はOwner許可により実施済み。

## 確定した範囲

- 背景と立ち絵を分離した16:9舞台を使い、非戦闘画面を再構成する。戦闘表示・報酬は維持し、戦闘の変更は後段TODOの覚醒技AI条件に限定する。
- ホーム／冒険／キャラクター／ショップ／交流場／別荘。内部の切替は上部タブ。ショップ上部の休むボタンは宿を兼ねる例外。
- 秘密の場所は鍵を使うエリア。既存の王都宝物庫を含む。装備の保管庫とは別。
- 既存の導入・探索・試練続行／帰還・スキップ・戦闘履歴・装備・STP／SP・覚醒設定・戦法・PT・会話・決闘・再振り・銀行に移行先を設ける。過去5章の初読と既読回想を分離し、購入条件を他の進行へ波及させない。
- 別荘は100,000 G。別荘購入で日誌・回想を利用でき、別の「日誌購入」はない。
- トロフィー棚は別荘購入後の不動産で500,000 G。別荘の上部タブで開き、達成済みの記念品と初撃破日時（日本時間）を表示する。購入済みはSOLD OUT。
- 透明な鏡は別荘購入後に1,000,000 Gで購入。次のショップ入場で指定イベント。以降、ショップで案内人の立ち絵を表示する。Owner提供の透過PNGとイベントスチルを登録済み。
- 交流場初回2ページと鏡イベントはOwner原稿を保持する。括弧は制作コメント、タイトルは回想用のみ。競売に言及する台詞からオークションを実装しない。
- 同行者は最大3人、本人込み4人。ホームの自キャラと小アイコンには権利情報ボタンを出さない。
- ホームに背景切替を設ける。Owner提供のAI背景は浅い洞窟が初期、黒晶洞が試練1クリア後、輝きの王国が試練2クリア後。既存の狩場の解禁条件と共通化する。選択を保存し、AI非表示中はAI背景を候補と描画から外して水晶へ戻す。保存した選択は消さない。
- パーティー欄はリーダーと同行者3人を2×2で並べる。リーダー表示は右寄せ。自キャラ名は上部とパーティー欄とも、既存の愛称優先・最大6文字の表示処理を使う。
- ホームのHP横に費用を明示した「＋ 10G」を置き、その場で既存の宿を利用できる。HPのみ回復、覚醒値保持、試練中は利用不可。ショップとrequest IDを共有し、応答消失後に画面を切り替えても二重課金しない。
- ホームのLv.右に未配分があるときだけ「STP 数値 →」を両テーマで読める赤で表示し、STP配分へ直接移動できる。
- STP画面は装備を除いた現在値と今回の配分に絞る。入力欄の左に50%、右に100%。ほかの能力への仮配分を除いた配分可能額から設定し、50%は切り捨てる。既存の一括確定とサーバー上限検証は維持する。
- スキルツリーは最後に選んだ系統を端末内にユーザー別保存する。未選択時は成長方針に合わせ、自由は戦技を開く。能力欄の見出しは左に小さめの愛称、右に小アイコンを置く。

## 冒険日誌

細かな分析画面にせず、クリアした試練、戦闘数、勝利数、与えたダメージ、受けたダメージ、スキップチケットを使った枚数、最後に案内人をげんこつした回数を表示する。

戦闘数・勝利数・ダメージの対象は探索、試練、力試し、および初回ジャイアントラットのtutorial。命名分岐のstoryと案内人決闘は対象外。スキップを戦闘数に加えず、チケット消費枚数を独立して表示する。本人のダメージとPT全体を混ぜず、本人の旧記録が不明なら不明のまま扱う。

4.2.1の恒久統計・履歴、既存スキップ決算、`SecretaryGuideConversationTotal.punch_count`を再利用する。戦闘ログの恒久保存や再決算を追加しない。

## トロフィー棚

「ワイバーンの翼」（試練1）、「デュラハンの兜」（試練2）、「魔剣のレプリカ」（夢の女王Lv1254）を表示する。棚の購入前の達成も対象とし、試練は既存の `first_cleared_at`、女王は初勝利時に `finished_at` と同じ日時で授与される売却不可の魔剣グラムの `acquired_at` を読む。再戦・棚購入で日時を上書きしない。戦闘receiptの恒久保持や全件走査をトロフィーの条件にしない。

所有日時のnullable列を追加する前進migrationを新設し、先行migrationや既存データを書き換えない。購入は既存のプロフィールlock・request ID契約を再利用し、棚の購入と別荘・鏡の購入を独立して扱う。

## 画像・設定

素材の親はOwner指定 `/srv/bot-assets/hakoniwa/`。既存peridotが非正方形PNGを配信できる仕組みを踏まえ、background／npc／eventを追加する。素材の制作区分・権利表記と、場面ごとの配置を登録する。価格や解禁条件を素材manifestへ入れない。

素材定義は `resources/scene-assets/scene-assets.json`。登録手順は同フォルダのREADME。ローカルプレビューで背景・立ち絵・スチル、PC／スマホ別の位置・高さ、制作区分・権利表記を設定し、追加用JSONを得られる。案内人とアキは透過PNG、鏡は縦長スチルとして全体を表示する。アキは480×640の解像度を踏まえて会話も全身を基本とする。これらは非AI素材で、AI表示設定にかかわらず表示する。画像生成への使用は禁止。権利表記はOwner指定を保持する。

ショップと交流場にもOwner提供の専用AI背景を登録。AI OFFでは両方とも水晶へ戻し、非AIの立ち絵は残す。別荘にはOwner採用済みのAI生成背景を追加し、同様にAI OFFで水晶へ戻す。輝きの王国の家をアキが補強・修繕した室内と、床の転移魔法陣を描いた背景で、配信用JPEGは519,770 bytes。登録画像はいずれも1MB未満。配信先manifestのSHA-256は `4a6a45a2afd990ea18edd8d5e6f7624ad6544c38112525196f3947b3674a7125`。

画面上のiは一つにまとめ、ダイアログ内で「立ち絵の権利情報」「背景の権利情報」「イベントスチルの権利情報」を素材ごとに表示する。表示されていない素材と自キャラは一覧へ含めない。

指定の非AIプレースホルダーは217,458 bytes、SHA-256 `179165959968473b0bcea8c1fc04e29449c51b516399697466ffd92c9c3136cf`。Git管理し、AI OFFや背景欠損時に使う。クレジット・リンク不要。Light/Dark双方で文字面と文字色を確認する。

Owner提供のペリドット全身図を `peridot/peridot-full-body.png` に追加する（665,412 bytes、SHA-256 `2cfdd706096a34ac9999421daaf187fb281d928e4a7f79d00f4a3718de659b8f`）。デフォルトのイラスト表示で大型画像を解決するときに使い、小アイコンは既存の `peridot.png` を使う。未配信なら従来画像へ戻る。シルエット版は新規作成せず、既存の表示設定・AI OFFの抑止を維持する。

ヘッダー設定へ移す名称：

- 一部で使用されているAI生成画像を表示する：表示する／表示しない。
- デフォルトの秘書画像の表示方法：イラスト表示／シルエット表示。

画像アップロードと権利編集は既存の所有者機能。表示抑止は閲覧者設定。設定の移動で既存値を初期化しない。

- 専用PostgreSQLの4.2.1 schemaに既存プロフィール・残高・16行AI・v2装備・戦闘履歴を置いてmigrationを適用し、既存値が完全に保持され20行保存できることを確認。fresh installも確認。

- PHPStan、Pint（変更PHP）、ESLint、TypeScript、Vite buildを確認。
- PR #16のレビュー修正: 明示AIの覚醒技decisionを通常skill使用数へ重複計上せず、実行イベントの技keyで一回だけ記録する。既存の蘇生代表をengine→statisticsまで拡張し、自動／明示の統計一致を確認。関連unit 29件が通過。
- 素材登録フォームはホーム背景のドット付きscene IDを許可し、ファイルパス検証は維持。祝福の初期タブは正規の `blessing_green` へ修正。既存画面代表15件と一時的なVue確認2件で確認し、低影響の表示修正だけの恒久testは追加しない。
