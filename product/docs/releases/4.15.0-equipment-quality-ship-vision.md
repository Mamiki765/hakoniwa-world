# 4.15.0 船の視界・装備Quality

基点 main は `b22a909562d1cbb0e96caf256f7bf6575736b5a4`（4.14.3 / v33）。application 4.15.0、World Ruleset は v34 一世代のみ追加する。

探索船の視界を5、戦艦を2とし、艦砲射程5を維持する。視界はWorldの現行Rulesetから解決し、建造済みの船にも適用する。船・Turnの作成Ruleset IDと旧snapshotは書き換えない。

新しい地底アクセサリーは全Affix枠を100%で付与する。枠数1/2/2/2、強度0.5/0.5/0.8/1.0は維持し、既存品へ効果を追加しない。武器・防具・共鳴結晶の抽選や強度は維持する。generator identityをv5へ進め、v1〜v4の保存済みpayloadを引き続き受理する。

`underground_owned_equipment.quality_percent` に入手時の未研磨Affix値から算出した整数を保存する。各Affixを同じIL・種類・rarityの実際の下限0〜上限100%へ正規化して平均し、アクセサリーは強度係数を掛ける。空き枠は0%、固定幅Affixは100%、既存生成アクセサリーのAffix0件は0%。最後に一度だけ整数へ四捨五入する。Affixなしの固定装備はnull（Quality —）。

追加migrationは旧生成品の原本payloadを200件ずつ読み、Quality列だけ補完する。研磨後の値、削除済み戦闘receipt、seedによる再抽選には依存しない。研磨・貸出は保存Qualityをそのまま引き継ぐ。貸出のIL同期は原本Affixのキー・種類・抽選係数を使い、数値だけを再計算する。現在の候補poolからの再抽選は行わない。

売却プレビューへQuality以下（0〜100）の任意条件を追加する。null品・装備中・売却不可品は対象外。確定は既存の具体的なID・価格一覧、lock、transaction、retry用request IDを維持する。保護・お気に入り機能はこのreleaseに追加しない。

既存の生成・研磨・貸出・まとめ売り・船の秘匿表示・艦砲攻撃・World移行の代表テストを拡張して検証する。Draft PRで共有し、merge・deploy・本番DB変更は実施しない。
