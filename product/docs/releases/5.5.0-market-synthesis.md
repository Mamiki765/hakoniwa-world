# 5.5.0 露店・合成・倉庫拡張

依頼ID `lapis-2026-10-18-release-550`。基準releaseは `b1523da34e7273a244e2f7c4197f8958bccf9ae9`、画面はラピスの `abd706637138310b5b08a6e7163b14ff5e241df8` を統合作業branchに取り込む。

API契約は peridot-notes の `lapis/2026-10-18-release-550-market-and-synthesis.md` と `lapis/2026-10-18-release-550-api-json-examples.md`（blob `a6245032a1adff4e66a5a706c45d77624d178b91`）。手持ちG払いと装備中Lv9999の自動fallback非採用は今回のOwner指示を優先する。

- 地底・交流場の即決露店。activeは同時5件、7日期限、価格はNPC売値以上、受取はfloor(price×9/10)。出品中も保管庫枠を使う。保護中の意図的な出品は可能で、出品後の装備・売却・研磨・保護変更を拒否する。
- 購入IL上限は装備可能な全所持装備・共鳴結晶の最大IL。装備不能のグラムを除外し、購入transactionでも再検査する。既存購入済み保管庫拡張を容量に反映する。
- 購入・取消・期限切れ・受領はプロフィールID順、出品、品物の順に排他を取る。購入と受領は結果snapshotを保存し、再送時に現在状態から再計算しない。売却履歴は品物の再移動・NPC売却後もsnapshotを表示する。
- 島放棄はactive出品を取り下げ、Secretary所有の品物・未受取代金を保持する。live出品・売却履歴を持つプロフィールの直接削除は外部キーで拒否する。
- 地上の既存distorted-stone-reminderと地底stateへ `market_attention` を返す。集計は `unclaimed_total` に統一する。GETは期限切れを既読にしない。画面が表示したIDだけをseen更新する。
- 地上は5種お守り・2種チケットの同種Lv合算（9999まで）と夢魔の紋章。装備中土台優先で収まる素材を提示し、POSTで同じID集合と土台を再検査する。未解決Turnと装備versionの整合を維持する。
- 夢魔は愛・双子星・三日月の紋章各Lv1から無料合成。自然回復と誘致の人口増加+100%、愛と併用で+110%。プレイヤー間交易可能、通常ガチャ・NPC出品からは除外する。
- チケットは既存 `ticket_item_id/request_key` を維持し `draw_count` を追加する。全消費の容量はused−1+回数、部分消費はused+回数。回数も再送内容に含める。
- 倉庫は100Pdで+50、最大250。付与・宝・交易場受領・怪獣drop・ガチャ・表示に共通容量を使う。

Rulesetはimmutable v39を変更せずv40を1世代だけ追加する。Behaviorは合成レシピidentity・素材/成果物・取引可否、Dataは露店上限/期限/率・合成上限・倉庫費用/容量・人口効果量、Flavorは新アイテム名称/説明。既存アイテムの通常入手max_levelと合成後保持上限を分け、既存ドロップ/ガチャの通常抽選範囲を維持する。

画面統合の追加修正は、露店ページ送り、出品直接遷移での上限取得、表示ID限定seen、保管庫の出品中表示/操作停止/露店導線、チケット上限fallback、拡張後の合成画面容量更新。固定レシピpreviewにもresult_levelを返す。

装備中の土台がLv9999の場合に未装備同士へ自動fallbackする案は未承認のため、この種類の候補を表示しない。正式採用する場合は別のOwner判断を必要とする。

main直接push、merge、本番deploy、実データ操作、認証・権限変更は実施しない。開発検証は8080環境と分離したworktree・DBを使う。
