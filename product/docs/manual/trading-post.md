# 交易場

交易場では、地上の資源と秘書のアイテムを、ほかの島とせり（競売）で売り買いします。代金は島の資金です。地底の装備やGとは関係ありません。地底の装備は、交流場の[露店](/manual/underground)で売り買いします。

## 入札する

商品の名前・数量・今の値段・終わるターンを見て、入札額を入れます。入札額は商品まるごとの値段で、1トンあたりの値段ではありません。

- 最初は開始価格以上、すでに入札があれば今の値段より高い額を入れます
- 自分の出品には入札できません
- **一番高い入札者になると、その額が資金から預けられます。** ほかの島がもっと高く入札すると、預けた資金は戻ってきます
- 預けている資金は建設などに使えません。次の計画の分も残しておきましょう

アイテムに入札するときは、秘書の持ち物に受け取る空きが必要です。

## 終わったら

終わるターンの更新で、一番高い入札者に商品が渡り、代金が支払われます。資源は島の蓄えへ、アイテムは秘書の持ち物へ入ります。蓄えの上限を超えた分は、ふだんどおり売られるか捨てられます。

## 出品する

| 項目 | 決まり |
|---|---|
| 同時に出品できる数 | 一つの島で{{ruleset:trading_post.player.active_listing_limit}}件まで |
| 出品の期間 | {{ruleset:trading_post.player.minimum_duration_turns}}〜{{ruleset:trading_post.player.maximum_duration_turns}}ターン |
| 出品できるもの | 取引できる資源と、秘書のアイテム |

- 出品したものは預けた扱いになり、その間は使えません。食料を出品すると住民が食べる分が減り、石油を出品すると燃料が減ります
- 装備しているアイテムは、外してから出品します
- 入札がなければ取り消せます。**一度でも入札が入ったら取り消せません**
- 売れなかったものは戻ってきます。「自動再出品」を選ぶと、同じ条件でもう一度出品します

売れたときに受け取れるのは、落札額の{{ruleset:trading_post.player.seller_proceeds_denominator}}分の{{ruleset:trading_post.player.seller_proceeds_numerator}}です。億円より細かい端数は切り捨てます。残りは手数料です。

## 箱庭連合の出品

プレイヤーのほかに、箱庭連合も資源やアイテムを出品します。いつもの商品と同じように入札できます。安いとは限らないので、数量と中身を比べて選んでください。

## 休眠中は

休眠中は、新しい出品と入札ができません。入札のない自分の出品は取り消せます。
