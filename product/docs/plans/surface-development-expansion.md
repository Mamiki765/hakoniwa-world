# 地上発展拡張：配置・電力・二次三次産業・属性魔力メモ

更新：2026-09-29。分類：**Ownerの構想・検討方向と未決事項**。未実装であり、現在のRulesetや4.6.0へ自動追加しない。

この文書は、地上を「人口を増やして既存施設を増やす」以外でも成長させるための常設メモ。数値・施設名・変換式・公開versionは未確定で、実装時は現行code / Ruleset / economy settlementを再確認する。

## 1. 目的

- 成熟した島に、人口・土地を単純増加させる以外の伸び方を作る。
- 上位産業は原則として、同じ人口・土地で基礎産業を増やすより高い費用対効果を狙う。
- 一方、ランキング・名声・景観などを目的とする施設は、意図的に経済効率が低くてもよい。
- 数字だけのLv上限解放ではなく、**地図上の配置そのものが攻略になる**方向を重視する。

## 2. 基礎資源から上位産業へ

現在考えている大枠：

```text
人口・基礎施設 → 作物 / 工業品 / 鉱物
油田           → 原油
発電設備       → 電力（新しい系統）

作物・工業品・鉱物・原油・電力
        ↓
二次 / 三次産業
        ↓
高付加価値品、商業・観光収益、高度設備など
```

- 「5資源すべてを毎回要求する」のではなく、産業ごとに必要な組み合わせを変える。
- 上位産業に大量の追加人口を要求しすぎると、結局「人口を増やすのが正解」へ戻るため、原料・電力・設備・配置を主な制約にする方向を検討する。
- 加工品を最初から大量の独立在庫へ増やすか、まずは加工収益としてsettleするかは未決。
- 生産・消費・通常売却の順序を固定し、同一turn内で資源が無限循環しないようにする。

候補例（名称・式は未決）：

- 作物 + 電力 + 工業品 → 食品加工 / 高級食品
- 工業品 + 鉱物 + 電力 → 精密工業 / 高度工業品
- 鉱物 + 電力 → 高度冶金 / 特殊合金
- 原油 + 工業品 + 電力 → 石油化学
- 食料・工業品・電力 + 人口/来訪需要 → 商業 / 観光

## 3. 配置シナジー

Ownerが面白いと考えているのは、箱庭RAの海あみゅや大農場系のような、**複数施設を特定の位置関係で置くと全体効率が上がる配置**。

重要なのは、単純な「上位施設へ置換」だけではなく、

- 周辺に何を置くか
- 何マス離れているか
- 海・森・山など地形を残すか
- 一つの支援施設を複数施設で共有できるか

を地図上で考える余地を作ること。

現時点では次の方式を比較中で、どれか一つに確定していない。

- 独立施設のまま隣接・範囲条件で効率を上げる
- 同種施設を合体 / rank upさせる
- 施設上限を伸ばし、災害耐性などを付ける
- 複数HEXを使う大型施設を作る
- 4マスを5マス相当、6マスを8マス相当のように「集約」で土地効率を上げる

2026-09-29時点では、**海あみゅ型の配置シナジーは特に好感触**。ただし固定レシピ・自動合体・任意の周辺bonusのどれを採るかは未決。

実装する場合、施設ごとに毎Turn全Mapを何度も走査する構造は避け、既存hex helperや近隣集計を再利用する。

## 4. 電力

電力は、作物・工業品・鉱物・原油と並んで上位産業を動かす新しい基盤候補。

未決事項：

- 食料や原油のようなstockpile資源にするか
- 発電量 / 消費量の**Turnごとの供給需要capacity**として扱うか
- 蓄電施設を作った場合だけ在庫を持たせるか
- 発電方式を何種類にするか

初期案としては、既存の農場・工場を電力導入と同時に停止させず、**新しい上位産業の稼働要件として電力を使う**方が扱いやすい。

発電候補として、原油を使う高出力型、土地を使う燃料不要型、余剰作物を使うバイオマス等は考えられるが、採用・数値は未決。

## 5. 地底との境界

ここは明確に分ける。

- 地底RPG攻略の地上還元は、**首都地下に建設する地下施設群**。
- 地底農場・地底工場等が基礎産業を補助することはある。
- 新しい地上産業、電力、配置シナジー、属性魔力を「地底攻略しないと遊べない」仕組みにはしない。
- 地底報酬を、地上産業の専用通貨・必須素材へ勝手に読み替えない。

地底と地上は相互に役立ってもよいが、入口と主進行は別系統を維持する。

## 6. 属性魔力と秘書

地上側の別成長軸として、属性魔力を高め、エルフの秘書が奇跡を起こす構想がある。

- 地底戦闘skillの延長として扱うとは決めていない。
- 島の地形、自然、施設、属性設備などから地上の魔力が生まれる案。
- 秘書はその魔力を扱う主体になり得る。
- 豊穣、防災、再生、航行、鉱脈、産業補助等は候補だが、効果・属性・発動方式は未決。
- 毎Turn必須クリックの作業にはせず、配置や蓄積で自然に働く仕組み、または大きな奇跡として使う仕組みを検討する。

「エルフ秘書がいるのに地底だけで活躍する」状態から、地上の島経営にも役割を戻す意図がある。

## 7. 最初の縦切り候補

実装承認ではない。将来着手する場合の小さな候補：

1. 電力の最小contractを決める。
2. 発電設備を1～2種類だけ追加する。
3. 上位産業を1種類だけ追加する。
4. 原料 + 電力 + 簡単な配置条件で基礎産業より高効率になることを確認する。
5. UIは在庫/供給、消費、稼働理由を見せ、「なぜ動いていないか」が分かるようにする。

最初から物流actor、全加工品在庫、巨大な汎用産業engineを作らない。

## 8. 実装前にOwnerが決めること

- 電力をstockpile / supply-demandのどちらで持つか
- 最初の発電方式
- 最初の上位産業
- 上位品を在庫にするか、その場で収益化するか
- 配置bonusの範囲と強さ
- 合体施設と配置シナジーを併用するか
- 災害耐性を上位施設の主効果にするか副効果にするか
- 属性魔力の種類、発生源、秘書の介在方法
- 地底施設から地上産業へどこまで補助を許すか

これらを決めるまで、汎用engineやschemaを先行実装しない。

## 9. 参考の扱い

2026-09-06に箱庭RA Final Editionの産業・電力・観光・施設発展を静的に分析済み。RAの数値や施設名を2S＋へそのまま移植することは決定していない。
