# コマンドの索引

開発計画に入れられるコマンドの一覧です。費用とターンを使うかどうかは、いまのゲームの設定から表示しています。

## 基本の使い方

1. 地図でマスを選ぶ（島全体へのコマンドは、どのマスからでも選べます）
2. コマンド欄からコマンドを選ぶ
3. 数量と入れる位置を決めて登録する

計画は上から順に、ターン更新のときに実行されます。計画が空のターンは自動で資金繰りになります。

- **ターンを使う**コマンドは、1件で1ターン分です
- **ターンを使わない**コマンドは、実行したあと同じ更新のうちに次の計画へ進みます。登録した瞬間に実行されるわけではありません
- 費用と条件は、実行するときにもう一度確かめられます。足りなければ失敗して、島のログに理由が出ます

コマンド欄はふだん、今の条件で実行できるものだけを出します。前の計画で地形が変わる前提で先に入れたいときは、「全部出す」にチェックを入れると条件外のコマンドも選べます。

## 数量の意味

| コマンド | 数量の意味 |
|---|---|
| 建設・増設 | 同じ場所で繰り返す回数。1ターンにまとめて増えるわけではありません |
| ミサイル | 撃ちたい本数。実際の本数は基地の力と資金で決まります |
| 海での掘削 | 油田探しに使う量。多いほど費用も上がります |
| 資金援助・食料援助 | 送る量 |
| 記念碑・船・怪獣派遣 | 種類を選びます。個数ではありません |
