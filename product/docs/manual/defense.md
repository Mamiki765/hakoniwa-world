# 怪獣と防衛

島が大きくなると、怪獣が現れるようになります。人口が多いほど、手強い怪獣も現れます。

## 怪獣が出たら

まず地図で怪獣のマスを選び、「マスの詳細」で種類・残りHP・特性を確かめます。

- 怪獣はターンごとに動き回り、踏んだ施設を壊します。ふつうの怪獣は、海・浅瀬・山や、採掘場・記念碑・首都などには入りません
- 種類によって、動く速さ、硬くなってダメージを受けないターン、倒し方の注意が違います
- 自分の島だけでなく、ほかの島の怪獣を倒すこともできます

## 怪獣の一覧

HPは出てくるたびに少し違います。中央銀行・中央穀倉がある島では、さらに手強くなることがあります。

[[index:monsters]]

人口が増えても、それまでの怪獣は変わらず現れます。いちばん上の段の怪獣は、ランク2の農場・工場・採掘場がない島では、ほかの怪獣に置き換わります。

### 硬くなるターン

サンジラとクジラが硬くなるかどうかは、**これから処理されるターン**の番号で決まります。いまがターン10なら、次の更新はターン11です。

### 大都市と怪獣

人口が{{ruleset:facility_rank_system.definitions.city.rank_one_maximum_population}}人を超えた都市は大都市になり、火災・地震を受けず、ふつうは怪獣の出てくる場所にもなりません。ただし、ほかに出てくる場所がない島では、キングいのら・珍獣ニョワミヤ・メカいのら零式に限って、大都市や空いた平地・荒地に現れることがあります。首都には現れません。

## 倒したとき

**経験値は、とどめを刺したときではなく、実際に減らしたHPの分だけ入ります。** 一覧の「減らしたHP 1ごと」の値に、減らしたHPを掛けた分です。ミサイル基地・海底基地で撃てば、その基地に入ります。硬くなっていたり迎撃されたりしてHPが減らなければ、経験値は入りません。

倒すと、残骸の価値の半分が倒した島の資金に、残りは怪獣肉になって怪獣がいた島へ届きます。秘書のアイテムが見つかることもあります。

## ミサイル

ミサイル基地（または海底基地）があれば、ミサイル発射のコマンドで狙ったマスへ撃てます。数量は撃ちたい本数です。

| 種類 | 特徴 |
|---|---|
| ミサイル | 安いが、狙った場所の周り{{ruleset:military.missiles.missile.deviation_radius}}マスに散らばります |
| PPミサイル | 周り{{ruleset:military.missiles.pp_missile.deviation_radius}}マスに散らばります |
| SPPミサイル | 狙った場所に正確に落ちます。高価です |
| 陸地破壊弾 | 地形そのものをえぐります |

費用は[コマンドの索引](/manual/commands)にあります。

**指定した本数が全部撃てるとは限りません。** 1ターンに撃てる本数は基地のLvで決まり、資金が足りなければそこで止まります。首都地下の地底ミサイル基地でも本数を増やせます。

### 基地のLv

基地は、怪獣のHPを減らすなどして経験値をためると、Lvが上がって撃てる本数が増えます。

## 防衛施設

防衛施設は、周り{{ruleset:military.defense_interception.radius}}マスに落ちてくるミサイルを迎撃します。

- **自分のミサイルも、怪獣のいるマスへのミサイルも迎撃します。** 防衛施設の近くの怪獣にはミサイルが届かないことがあります。怪獣が倒せないときは、近くの防衛施設を確かめてください
- ほかの島の防衛施設も、同じように迎撃します
- 防衛施設そのもののマスに落ちたミサイルは迎撃しません。ただし、SPPミサイルでは防衛施設を壊せません
- 自分の防衛施設にもう一度防衛施設を建てると、自爆して周りにも被害を出します
- 怪獣が防衛施設を踏んだときも自爆します
- ハリボテは見た目だけの防衛施設で、迎撃はしません

防衛施設を抜けたミサイルも、秘書の技能「最終防衛ライン」で止められることがあります。

## 秘書と船も戦える

秘書が弓を装備していると、ときどき怪獣を射ます。戦艦を持っていれば、近くの怪獣や海賊船を自動で撃ちます（[海と船](/manual/sea)）。

## KARMA

KARMAは、ほかの島への攻撃で上がる値です。ふだんは0で、高いほど危ない島として扱われます。上限は{{ruleset:karma.maximum}}、下限は{{ruleset:karma.minimum}}です。

### 上がるとき

ほかの島へ被害を出すと上がります。ただし、**相手の島のKARMAが0以下のときだけ**です。

| ほかの島に出した被害 | 上がる値 |
|---|---:|
| 地形を変えた | ＋{{ruleset:karma.impact_points.terrain}} |
| 施設や集落を壊した | ＋{{ruleset:karma.impact_points.settlement_or_facility}} |
| 首都に被害を出した | ＋{{ruleset:karma.impact_points.capital_above_minimum}} |
| ランク2の施設の規模を減らした | ＋{{ruleset:karma.impact_points.facility_scale_damaged}} |
| 陸地破壊弾などでランク2の施設の規模を減らした | ＋{{ruleset:karma.impact_points.facility_scale_land_damaged}} |
| 海底基地・海底都市・海底消防署を壊した | ＋{{ruleset:karma.impact_points.seabed_base_destroyed}} |
| 陸地や海底油田を壊した | ＋{{ruleset:karma.impact_points.land_destroyed}} |
| 船を沈めた（これは相手のKARMAに関係なく上がります） | ＋{{ruleset:surface_ships.missile_impact.foreign_sink_karma}} |

その他、破壊的な行動をするとKARMAが大きく蓄積します。

**怪獣がいる範囲を狙ったミサイル・PPミサイル・SPPミサイルは、外れてほかの島を壊しても上がりません。** 陸地破壊弾は上がります。

### 下がるとき

- KARMAがプラスのあいだ、{{ruleset:karma.decay_interval_turns}}ターンごとに{{ruleset:karma.decay_amount}}ずつ下がります
- ほかの島の怪獣を倒したターンは{{ruleset:karma.foreign_monster_kill_reduction}}下がります。0より下にもなります
- KARMAがプラスの島は、攻撃を受けるたびに{{ruleset:karma.victim_reduction_per_impact}}ずつ下がります
- 休戦に入ると{{ruleset:karma.recovery_entry_reduction}}下がります

### KARMAが高い島

KARMAがプラスの島を、KARMAが0以下の島が攻撃すると、箱庭連合から報奨金が出ます。1回の被害ごとに、相手のKARMAと同じ億円です。

上限を超えて上がる分は、箱庭連合からの制裁ミサイルになります。超えた分1につき1発、自分の島のどこかに落ちます。防衛施設と秘書の「最終防衛ライン」で迎撃できます。

## 怪獣派遣

怪獣派遣のコマンドで、ほかの島へ機械の怪獣を送り込めます。
