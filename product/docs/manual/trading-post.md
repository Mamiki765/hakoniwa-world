# 交易場

交易場は、地上の資源と地上用秘書アイテムを、ほかの島と競売で売買する場所です。代金には地上の資金を使います。地底の装備をGで売る宝物庫とは別です。

## 商品を探して入札する

商品名、数量、現在価格、終了ターンを確認します。アイテムではLvと効果も見てください。入札額は商品全体の価格で、資源一単位の単価ではありません。

最初は開始価格以上、既に入札があれば現在価格より1億円以上高い額を指定します。自分の出品には入札できません。

**最高入札になると、その金額が手持ち資金から預けられます。** 別の島が上回る入札をすると、前の最高入札者へ返金されます。自分の最高額を上積みする場合は、新しい総額を入力します。

預けた資金は、建設やミサイルには使えません。次の開発計画の費用も残しておきましょう。

## 終了はターンで決まる

終了ターンの更新で、最高入札者への引き渡しと代金精算が行われます。画面を開き直すだけでは終了しません。

落札した資源は島の在庫へ、アイテムは秘書の所持品へ入ります。資源が容量を超えると、超過分の売却・破棄が起こる場合があります。結果は島のログで確認できます。

## 自分で出品する

| 項目 | 条件 |
|---|---|
| 同時出品数 | 一島につき3件まで |
| 開始価格 | 1億円以上 |
| 出品期間 | 3～84ターン |
| 出品できる品 | 取引可能な資源・地上用秘書アイテム |

出品すると商品は預けられ、その間は使えません。食料を出品すれば住民が食べる在庫が減り、石油を出品すれば船に使える燃料が減ります。

装備中のアイテムは、先に外してから出品してください。

### 取り消しと再出品

入札がなければ取り消して商品を返してもらえます。**入札が一度でも入った出品は取り消せません。**

入札なしで期間が終わった商品は通常返却されます。「自動再出品」を選ぶと、売れなかった商品を同じ期間でもう一度出品します。価格を変えたい場合は、入札のないうちに取り消して出し直しましょう。

## 売れたときの代金

出品者が受け取るのは、落札価格の90%を億円単位で切り捨てた額です。残りが手数料になります。

| 落札価格 | 受取額 | 手数料 |
|---:|---:|---:|
| 100億円 | 90億円 | 10億円 |
| 105億円 | 94億円 | 11億円 |
| 1億円 | 0億円 | 1億円 |

資金上限に達していれば、受取額を全て保管できない場合もあります。

## 箱庭連合の出品

プレイヤーだけでなく、箱庭連合から資源や秘書アイテムが出品されることもあります。通常の商品と同じように入札します。

不足している資源の補給や、欲しいアイテムの入手に使えます。価格が必ず割安とは限らないので、数量と効果を比べて選んでください。

## 容量と休眠の注意

出品中の資源も保管容量を使い、最高入札中の預託資金も資金上限の計算に含まれます。アイテムへの入札には、受け取る所持枠も必要です。

休眠中は新しい出品・入札が制限されます。入札のない自分の出品は、休眠中でも取り消せます。

基本の資源価格は[人口と資源](/manual/economy)、アイテムの使い方は[地上の秘書](/manual/secretary)を参照してください。
