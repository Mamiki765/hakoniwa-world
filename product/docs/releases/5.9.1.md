# 5.9.1 マニュアル・故障修理・海底工作を見つけやすく

application **5.9.1 / Ruleset v42**。5.9.0のmain `02977244a467df549ca9b5d96f574aa101d569ca` を基準にする画面の修正。本書はコードの範囲を示し、本番への適用完了を意味しない。

## きっかけ

要望 INQ-000018。風力発電所の故障に気付いたプレイヤーがマニュアルを探したが見つからなかった。ログイン中の上の帯は横スクロールで、スマホでは右に動かせると気付かれず、末尾の「マニュアル」「オプション」などが画面外にあった。

## 変更

- 上の帯: 幅に入りきらない項目を、右から順（マニュアル → オプション → 交易場 → 地底 → 秘書）に「☰」のメニューの上へ回す。TOPと自島へは帯に残す。回した項目に赤丸があれば「☰」にも出す。入りきる幅とログイン前は従来どおり。
- 故障の印: 持ち主の地図だけ、故障して修理を待つ施設（現状は風力発電所）のマスの左上に小さな「！」を出す。判定はserver（`WindPowerRepairPolicy::needsRepair`、地図セルの`needs_repair`）。
- 修理を先頭に: コマンド一覧で半額修理になる建設に`repair`を付け、「修理」欄として先頭に出す（通常の欄からは抜く）。予約位置より前の計画を反映した状態で判定する。
- 海底工作船: 「真下に建築」の欄を通常の欄より上へ。欄の並びは 修理 → 真下に建築 → 通常 → 輝石。

## 範囲外

Ruleset snapshot・世代、DB構造、migration、依存は変更しない。ターンの処理と修理の費用・条件は変えない。

最終HEADの検証結果とCIはリリースPRに記録する。
