# 4.9.0 船一覧

自国の船が地上マップに散らばっていても、生存状況をまとめて確認できる小窓を追加する。資源・売却方針の行で、デイリークエストの左にある「船一覧」から開く。

- 生存している自国船をRulesetの種類順に並べ、同じ種類はID順とする。1隻1行で、例えば `漁船 (2,4) HP1/1 ランダム` と表示する。
- 座標はマップと同じ絶対x/y。進行方向は既存の進路操作と同じ東・北東・北西・西・南西・南東を使う。
- 軍艦など `heading_only` の船で進路がランダム設定（null）の場合は「待機中」。他の船のnull進路は「ランダム」。種類名・並び順・移動方式は船自身のRuleset定義を参照する。
- 開くたびに最新情報を取得し、「更新」でも再取得できる。マップで読み込んだchunkには依存しない。廃船・NPC船・他国船は含めない。
- 読込中・空の一覧・取得失敗を表示し、失敗後も更新できる。既存の日課小窓の配色と寸法を使い、長い一覧はスクロールする。閉じるボタン、Escape、背景クリックで閉じる。native dialogでフォーカスを小窓内に保ち、閉じると入口に戻す。

認証必須GET `/api/v1/nations/{nation}/ships` は、その国のmembershipがある利用者だけに公開する。active・dormant・recoveryで閲覧できる。自国船は既存の船由来視界で所在とHPを確認でき、進路も自国船だけに公開されているため、その境界を維持する。公開島プレビューに一覧は追加しない。船の操作、移動処理、Ruleset、永続状態、schemaは変更しない。

ユーザー向けの新機能なのでapplication versionをminorの4.9.0へ進める。レビュー修正中は版を据え置き、P0〜P2解消後の最終commitで更新する。

検証は、新規GETの認可・生存船filter・順序を既存の船舶APIテストへ1件追加し、表示側は新しい小窓の読込・方位・待機表示・更新を1件で確認する。既存テストでは今回のGETと一覧を通らないため、この独立した失敗条件を補う。型検査、lint、build、変更PHPのPint・PHPStan、および一時fixtureを使った実ChromeのPC幅・320px幅・light/dark・キーボード・空一覧・失敗後の再取得を確認する。最終HEADのrepository-wide検証はQuality CIを正本とする。
