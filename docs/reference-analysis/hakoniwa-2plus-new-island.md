# 箱庭諸島2＋ 新規国家・島の登録

## 入口

CGI入力の `NewIslandMode` が `MODE_NEW` を設定し、`main` が `NewIsland::main` を呼ぶ（`HakoIO::cgiInput`, `hako_io.c:358-360`; `main.c:67-70`）。中心座標は `PointX`, `PointY`、名称は `IslandName`、パスワードは `Password`, `Password2` から得る（`hako_io.c:397-436`）。

## 検証順

`NewIsland::main` は共有マップを読み、次を順に検査する。

1. 国家数が `maxNumber` 未満（`new_island.c:4-12`）。
2. 名称が空でない（`14-19`）。
3. 禁止名・禁止文字を含まない（`21-26`; `Util::badNameCheck`, `util.c:5-20`）。
4. 名称が重複しない（`28-33`; `Util::dupCheck`, `util.c:34-42`）。
5. パスワードが空でない（`35-40`）。
6. 確認用パスワードと一致する（`42-48`）。
7. 指定中心から半径5の91セルがすべて中立（`50-59`; `Map::countNeutral`, `map.c:126-140`）。

成功すると `nextID` を不変IDとして割り当てて増分し、国家数を増やす（`new_island.c:61-71`）。

## 初期位置の決め方

**確定**：サーバーは空き地を自動検索しない。利用者が指定した `PointX`, `PointY` をそのまま中心 `centerX`, `centerY` として使う（`new_island.c:50-53,70-75`）。必要距離は「中心から半径5の91位置に、ownerが0でないセルが一つもないこと」である。これは他国中心間距離そのものを比較する実装ではない。

**問題候補**：中心座標自体の範囲検証がない。`Map::countNeutral` は範囲外を中立として数え、生成処理は範囲外セルをスキップする（`map.c:127-139`; `new_island.c:84-209`）。端では初期領域が欠け、完全な範囲外でも検査を通過し得る。

## 初期地形生成

生成は指定中心を基準に次の順で共有マップを書き換える。

1. 半径3..5に相当する添字19..90を、所有者0の深海へ初期化する（`new_island.c:84-94`）。
2. 半径0..2の19セルを、自国所有の通常荒地へ初期化する（`96-105`）。
3. 半径4内のランダム位置を100回選び、周囲に陸があれば、荒地→人口0の平地、浅瀬→荒地、深海等→浅瀬の順に成長させる（`107-134`）。
4. 半径2内へ森を3セル置く。`param=5`、すなわち500本（`136-151`）。
5. 森や既存の有人口町を避けて村を2セル置く。各 `param=5`、すなわち各500人（`153-170`）。
6. 森や有人口町を避けて山を1セル置く。採掘規模は0（`172-189`）。
7. 森、山、有人口町を避けてミサイル基地を1セル置く。経験値0（`191-209`）。

最低限、村2セルにより初期人口は合計10単位=1,000人となる。ただしランダムな上書き順により、それ以前の平地・荒地等の正確な配置形状は毎回異なる。

初期施設はミサイル基地1、山1、森3、村2。農場、工場、採掘場規模、防衛施設、海底基地、記念碑、首都は作らない。

## 配置失敗条件

- 国家数上限。
- 空名、禁止名/文字、重複名。
- 空パスワード、不一致。
- 半径5内に1つでも他国所有セルがある。

**確定**：自動候補探索、空き領域の予約、別候補への再試行、生成ループの試行上限はない。端で有効セルが不足しても、森・村・山・基地を置く `while` が条件を満たせなければ終了しない可能性がある（`new_island.c:136-209`）。

## 同時登録時の競合

本来は `main` 冒頭のグローバルロックが、マップ・情報読込から登録書込までを直列化する意図と読める（`main.c:21-23`; `new_island.c:220-225`）。しかし `Util::lock` の `flock` 成否判定はPOSIX慣例と逆に見えるため、実際に排他が成立するとは静的解析だけでは確定できない（`util.c:123-143`）。

排他が機能しなければ、同じ空間の同時取得、`nextID` 重複、`info.cgi`/`map.cgi` の後勝ち上書きが起こり得る。新作ではDBトランザクション、位置予約、一意制約を使うべきである。

## 書込と表示中心

登録後、20件の初期コマンドを資金繰りで作り、履歴を出し、コマンド・情報・マップの順で別々に保存する（`new_island.c:211-223`; `Command::initialize`, `command.c:41-48`）。3ファイルを束ねるトランザクションはない。

`centerX/Y` は所有者画面の中心、難民受入れ半径5の中心、記念碑攻撃の目標中心に使われる（`Map::getBoatPeople`, `map.c:1076-1105`; `Map::process`, `map.c:718-733`）。`Move` コマンドで任意の自国セルへ変更でき、コスト1,000（`command.c:616-620`; `costTable`, `command.c:5-35`）。

中心は首都施設ではないため、地形破壊・占領とは独立して座標だけが残り得る。

## 新作構想との差分

- 新作の「国家作成時に首都を自動配置」は完全な新仕様。
- 首都を消滅・占領不可にするなら、通常の `Land.kind/owner` だけでは表せない不変ルールが必要。
- 首都人口の割合減少と最低保証は、セル `param` の通常人口成長・破壊とは別のドメインルールにする必要がある。
- 空き地探索は、ユーザー指定一点判定から、チャンク横断の候補生成・距離制約・予約へ置き換える必要がある。
- 初期国境、首都周辺保護半径、他国との距離、海岸条件、世界拡張を発動する閾値は設計判断として残る。
