# 災害と防災

災害には、広い範囲を襲うもの、対象マスごとに判定するもの、島の面積を条件にするものがあります。発展に合わせて備えを整え、被害を受けても立て直せる島を目指しましょう。

## 主な災害

| 災害 | 主な被害 | 備え方・注意 |
|---|---|---|
| 火災 | 都市・工場などが焼失 | 近隣の森や記念碑で防護。大工場は規模損失で耐えます |
| 地震 | 大きな都市、工場、ハリボテなどに被害 | 大工場の耐性が役立ちます |
| 津波 | 水域に近い集落や施設へ被害 | 周囲に陸地の多い場所を活用します |
| 台風 | 農場・ハリボテなどへ被害 | 森や記念碑、大農場の台風耐性 |
| 流星群 | 複数の着弾地点が破壊される | ランク2施設は対象の着弾で規模を減らして耐えます |
| 巨大隕石 | 中心と周囲に大きな地形被害 | ランク2でも中心直撃は防げません |
| 噴火 | 中心が山になり、周囲の地形や施設も変化 | 地形そのものが変わります |
| 地盤沈下 | 広げすぎた島の沿岸と浅瀬が沈む | 陸地面積と安全面積を確認します |

地ならしによって地震が起きる場合もあります。通常の整地との費用・ターンの違いだけでなく、この危険も考えて使ってください。

## 森と台風

通常の農場の台風被害率は、周囲の防護数をNとして、**max(0, 6−N)÷12**です。森や記念碑で農場を囲むと、失う確率を下げられます。

大農場では、これが**max(0, 3−N)÷12**になります。「森3個分の台風耐性」とはこの効果です。

| 周囲の防護数N | 通常農場 | 大農場 |
|---:|---:|---:|
| 0 | 6/12 | 3/12 |
| 1 | 5/12 | 2/12 |
| 2 | 4/12 | 1/12 |
| 3 | 3/12 | 0 |
| 6 | 0 | 0 |

大農場自身の判定を軽減する効果です。別の農場から見て、大農場が本物の森三マスになるわけではありません。

**被害判定に当たった場合は、大農場も消滅します。** 台風を規模損失に置き換える耐性ではありません。

## ランク2の規模損失型耐性

ランク2施設は、一部の攻撃や災害で全損する代わりに規模が減ります。表の人数は、被害が成立したときの減少量です。

| 被害 | 大農場 | 大工場 | 大採掘場 |
|---|---:|---:|---:|
| 通常ミサイルなど、荒地・焼け野原にする破壊 | −1,000人 | −5,000人 | 通常の破壊では壊れない性質を維持 |
| 陸地破壊弾・隕石など、陸地をえぐる破壊 | −3,000人 | −15,000人 | −2,000人 |
| 火災・地震による工場被害 | 対象条件は従来どおり | −20,000人 | 対象条件は従来どおり |
| 巨大隕石の中心直撃 | 全損 | 全損 | 全損 |

耐えた施設は、その場に規模を減らして残ります。旧上限以下になった場合はランク1へ降格し、次の被害からは耐性を失います。

怪獣による踏み荒らしには、この耐性は働きません。また、自分で整地・掘削して撤去する操作や、表にない全ての災害を防ぐ効果ではありません。

## 中央施設の被害

中央銀行・中央穀倉は地震では被害を受けず、通常・PP・SPPミサイルも効きません。一方、次の被害では施設を失う代わりにLvが減ります。

| 被害 | Lv減少 |
|---|---:|
| 陸地破壊弾・津波 | −1 |
| 流星群 | −5 |
| 巨大隕石 | 中心−20、周囲1マス−5、周囲2マス−1 |
| 噴火 | 中心−5、周囲1マス−1 |
| 地盤沈下 | −5 |

Lvが0になると施設は消え、マスは中立の浅瀬になります。中央施設は周囲の火災・台風を森と同様に防護しますが、施設自身があらゆる被害へ無敵になるわけではありません。

## 巨大隕石の距離別の被害

普通の陸地では、中心は海、周囲1マスは浅瀬、周囲2マスは荒地になる強い破壊です。元の地形や首都などには別の扱いがあります。

大農場・大工場は、周囲1マスなら「陸地をえぐる破壊」、周囲2マスなら「荒地・焼け野原にする破壊」の規模損失で耐えます。山や採掘場に、もともと対象外の外周被害が追加されるわけではありません。

**中心直撃は、最高規模のランク2でも防げません。** 一方、流星群の各着弾は、全てが巨大隕石の中心と同じ扱いになるわけではなく、対象の耐性が働きます。

## 地盤沈下と100マス

基本の安全面積は陸地100マスです。100マスは領有できる絶対上限ではなく、地盤沈下の抽選対象になるかどうかの基準です。

有効な安全面積を超えた島には、基本で毎ターン2%の発生判定があります。補正がある場合は、ゲーム画面の現在値を確認してください。

自領の浅瀬が海に、自領の水域に接していた沿岸の陸地が浅瀬になる被害です。山は面積に数えますが沈みません。同じ一回の沈下で、新たな浅瀬から際限なく内陸へ連鎖するわけではありません。

土地を広げるだけでなく、ランク2や地底設備で、一マスあたりの働きを増やすことも発展の方法です。

## 被害に遭ったら

島のログで、災害名・座標・規模の変化を確認します。ランク2が耐えた場合は、整備で規模を戻せます。ただし降格していたら、再び旧上限を超えるまで耐性はありません。

農場を失ったら食料収支を、工場や採掘場を失ったら資金収支と海底都市の維持資源を確認しましょう。復旧費を作るために食料まで売りすぎると、災害の後に飢饉が重なることがあります。

首都には人口を減らして首都自体を残す扱いがあります。地底設備も地上の施設とは別の場所にあるため、島の立て直しを支える手段になります。
