# 4.12.0 油田開発・船舶運用・海軍

リリース番号はapplication `4.12.0`、Ruleset `hakoniwa-2s-plus-v30`（[PR #193](https://github.com/Mamiki765/hakoniwa-world/pull/193)）。v29からforward移行する。既存の資産・技能・船舶・保存済みTurnのidentityは保持し、油田開発をLv0／XP0で追加する。未解決のproduction TurnがあるWorldは移行を拒否する。

| 技能 | 効果 | XP |
|---|---|---|
| 油田開発 | 油田1基の基本500万バレルにLv万バレルを加算 | 油田探索成功1件につき基本XP1。失敗・投資額・産出量は数えない |
| 船舶運用 | 漁船の漁獲・観光船の収入をLvごとに1%加算、既存整数計算で切捨て | 既存の成功航行XPを維持 |
| 海軍 | 自国戦艦への通常1HP攻撃を `15×Lv/(Lv+20)%` で回避 | 既存のXP条件を維持 |

油田開発の次Lv必要XPは `(Lv+1)^2`、余りを繰り越す。通常の経験値装備補正を適用し、平和系衣服3種も対象とする。効果はTurn開始時の技能値を使う。海軍は残HP1も対象とし、直接轟沈・直接撤去・燃料切れを除外する。判定は既存Turn乱数の専用streamを使い、同seed再実行で同値になる。

秘書表示は食料・工業品・鉱物・石油・電力の5技能を先頭へまとめ、続いて既存技能を並べる。森林管理の名称は維持する。効果とXP条件は既存の小さく薄い表示を使う。

## 過去の油田発見XP

v30移行時に各既存Worldの監査ID上限とTurn上限を保存する。migrationはXPを加算しない。新規Worldには過去分の境界を作らない。

まず候補を読む（省略時もdry-run）。本PRでは本番加算を行わない。

```sh
php artisan hakoniwa:backfill-oil-discovery --world=1 --dry-run
```

対象は残存する `command.seabed_oil_search` の `metadata.found=true`。定例監査圧縮の対象外だが、欠損した履歴は復元・推定しない。audit／World／国／Turn／run／queueを示し、完成した非dry-runかつv30以前の成功だけを数える。同一実行の重複eventは除外し、境界後とv30の発見はオンラインXPとの二重加算を避けて除外する。

帰属は現owner membershipを使う。破棄国はcompletedの `nation_creation_requests.user_id` または `nation.created.actor_user_id` を照合し、一意に決まる秘書へ帰属させる。欠損・競合・技能欠如は`skipped`へ残す。候補1件＝XP1として、過去装備による倍率を推定しない。

将来Ownerが本番加算を承認した場合だけ、候補・除外・未解決行を確認して `--apply` を使用する。未解決行があるbatchは加算を拒否する。World lockと地上状態／技能行lockの同一transactionで加算し、World単位の`applied_at`で一回限りとする。適用済みの再実行は加算しない。保存境界や適用印を削除・変更しない。
