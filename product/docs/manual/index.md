# 箱庭諸島２S＋マニュアル

箱庭諸島２S＋は、共有の海に自分の島を作り、人口と産業を育てるゲームです。農場で食料を作り、工場や採掘場で資源を生産し、それを売って次の開発に使います。災害や怪獣への備え、船の運用、ほかの島との取引も島主の仕事です。

島の経営を助ける秘書は、地底では冒険者になります。戦闘を重ね、能力やスキルを育て、装備を集めて試練に挑みましょう。地底で解放した設備枠は、地上の島の強化にも使えます。

**最初から全部を覚える必要はありません。** 初めての方は「はじめの一歩」から、既に遊んでいる方は調べたい項目から読んでください。

## 二つの時間の進み方

**地上は、定期的なターン更新で進みます。** 開発計画を登録しただけでは建設は完了しません。更新で計画が実行され、生産、人口の変化、船の航行、怪獣や災害の処理が行われます。次の更新時刻はゲーム画面で確認してください。

**地底は、自分で探索や次の戦闘を選んで進めます。** 地上の更新を待たずに遊べますが、戦闘後には10秒の待ち時間があります。戦闘は、事前に設定した装備・スキル・AIを使って自動で進みます。戦闘ログを読む速さで結果は変わりません。

ただし、地底で解放した「地底都市」「地底農場」などの設備の建設・撤去は、地上の開発計画です。こちらは地上のターンを使います。

## 混同しやすい数字

| 表示 | 何に使うか |
|---|---|
| 資金・億円 | 地上の建設、ミサイル、船、資源取引など |
| 小麦・魚・怪獣肉・工業品・鉱物・石油 | 地上の食料、生産、売買、燃料など |
| 輝石の欠片・G | 地底の宿、武具購入、銀行、再振りなど |
| 地上の秘書技能Lv | 農業政策や怪獣討伐など、島の仕事で育つ技能 |
| ミサイル基地の経験値・Lv | その基地の発射能力を育てる値 |
| 地底の戦闘Lv・EXP | 地底で戦って秘書を育てる値 |
| STP | 地底の五能力へ割り振るポイント |
| SP | 地底のスキルを取得・強化するポイント |
| IL | 地底装備のアイテムレベル。秘書の戦闘Lvとは別 |

地上の秘書アイテムと地底装備は、倉庫も装備欄も効果も別です。地上の弓を装備しても、それがそのまま地底の武器になるわけではありません。

## 今すぐ始めるなら

島を登録したら、食料を作る農場と、村が育つための平地を確保しましょう。開発計画を登録し、次の更新後に島のログを確認します。工業品や鉱物が余るようになったら、資源売却で建設資金へ変えられます。

ターン待ちの間には、秘書の名付けを済ませて地底の導入を進められます。浅い場所で装備と経験値を集め、少しずつ強い相手へ挑みましょう。

操作に迷ったときは[はじめの一歩](/manual/beginner)、何かが減った・止まったときは[困ったとき](/manual/faq)へ。参加時には[利用ルール](/community-guidelines)も確認してください。
