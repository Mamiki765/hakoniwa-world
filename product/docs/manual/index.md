# 箱庭諸島２S＋マニュアル

箱庭諸島２S＋は、みんなで一つの海を分け合い、自分の島を育てるゲームです。農場で食料を作り、工場や採掘場で資源を作って売り、そのお金で次の開発をします。災害や怪獣に備え、船を出し、ほかの島と取引するのも島主の仕事です。

島を手伝う秘書は、地底では冒険者になります。地底で戦って育て、装備を集め、試練に挑みましょう。

**全部を覚える必要はありません。** 初めての方は[はじめの一歩](/manual/beginner)から。施設やコマンドを調べたいときは[施設の索引](/manual/facilities)と[コマンドの索引](/manual/commands)をどうぞ。

## 二つの時間

**地上（島）は、決まった時刻のターン更新で進みます。** 計画を入れておくと、更新のときに実行されます。

**地底（冒険）は、自分のペースで進みます。** ターン更新を待たずに、探索や戦闘を続けられます。

次のターン更新の時刻は、ゲーム画面の上に出ています。

## 詳しいことはゲームの中で

このマニュアルは遊び方の地図です。細かい数字や効果は、ゲームの画面がいちばん新しくて正確です。

- 施設や地形の様子は、地図のマスを選ぶと出る「マスの詳細」で
- コマンドの費用と条件は、開発画面のコマンド欄で
- 秘書の技能・アイテムの効果は、秘書の画面とアイテムの効果欄で
- 地底のスキルや装備は、地底の各画面で

参加する前に[利用ルール](/community-guidelines)も読んでおいてください。
