# 地上の秘書

秘書は島の開発や防衛を助ける存在です。地上では仕事に応じた技能を育て、弓・衣服・アクセサリーを装備できます。地底では同じ秘書を冒険者として育てますが、地上技能と地底の戦闘Lvは別の成長です。

## 名付けとプロフィール

秘書の名前がまだない場合は、「？？？」の導線から名付けを済ませます。名前を付けると、地底の導入へ進めるようになります。

プロフィールでは紹介文や画像などを設定できます。ほかの人に公開される項目もあるので、個人情報やログイン情報は書かないでください。画像の閲覧設定は、表示のための設定です。

秘書はプレイヤーに属します。島を作り直しても残る秘書の成長と、島に属する土地・施設・船は別です。

## 技能は仕事で育つ

地上の技能には地底のSPを使いません。対応する仕事で経験値を得て、技能Lvが上がります。計画を登録しただけでなく、実行結果が重要です。

| 技能 | 主な経験の機会 | 効果の要点 |
|---|---|---|
| 農業政策 | 農場の建設・増設 | Lvごとに小麦生産＋0.1% |
| 特産品開発 | 工場の建設・増設 | Lvごとに工業品生産＋0.1% |
| 金鉱脈調査 | 採掘場の建設・増設 | Lvごとに鉱物生産＋0.1% |
| 森林管理 | 植林・伐採 | Lvごとに森林成長・伐採収入＋1% |
| 最終防衛ライン | 自領へのミサイル到達 | 技能Lvに応じた本数のミサイルを迎撃 |
| 怪獣討伐 | 秘書の弓・地底ミサイル基地による実HPダメージ | 怪獣への攻撃で育つ技能 |
| 少子化対策 | 人口の最高到達記録の更新 | Lvごとに通常成長上限＋50人、誘致上限＋100人 |
| 不屈 | ターン終了時の人口の純減 | Lvごとに自然人口増加＋0.25% |
| 船舶運営 | 船の成功航行 | 経験値は育ちます。固有効果は準備中 |

農場・工場・採掘場の建設・整備や植林・伐採は、一回の成功で基本1EXPを得ます。反復回数を大きく登録しただけで、その回数分が一度に入るわけではありません。

技能Lvの合計は、資金と食料の基本容量にも作用します。合計Lvごとに1%ずつ増えるため、色々な仕事を経験することが備蓄の余裕にもつながります。

### 最終防衛ライン

通常の防衛施設の迎撃が先に行われ、そこを通過した自領へのミサイルを秘書が止めます。迎撃できる本数は技能Lvに関係します。

自領へ到達したミサイルは、迎撃されたものも含めて経験の対象になります。ただし、秘書の迎撃で怪獣のいるマスを守ってしまうことはありません。

### 怪獣討伐

秘書の弓や地底ミサイル基地が、**実際に減らした怪獣のHPごと**に経験値を得ます。地上のミサイル基地・海底基地が攻撃した分は、その基地の経験値です。

最後の一撃だけの経験値ではなく、地底で戦闘Lvを上げるEXPでもありません。詳しい受取先と数値は[ミサイルと怪獣](/manual/advanced)を参照してください。

## 地上アイテムの装備

地上の装備枠は5つです。弓は一つ、衣服も一つまでで、ほかにアクセサリーなどを選べます。同じ種類のアイテムを複数装備して効果を重ねることは、原則できません。

**持っているだけでは装備効果は働きません。** 所持品から装備し、表示される効果を確認してください。倉庫には最大50個を所持できます。

アイテムは品ごとにLvや効果が異なります。同じLvでも用途は違うので、発展・防衛・経験値など、今ほしい効果に合わせて選びましょう。

## 弓の違い

弓は、条件を満たす怪獣がいると、ターンごとに一定確率で攻撃します。対象の場所や状態によっては攻撃しません。

| 弓 | 特徴 |
|---|---|
| 古びた弓 | 最初の弓。基本の攻撃率10%、通常1ダメージ |
| エルフの弓 | 基本の討伐向け。攻撃率は11＋アイテムLv% |
| 遠当ての弓 | 海上のあおいのらも狙えます。攻撃率は11＋アイテムLv% |
| 機械弓 | 攻撃率は9＋アイテムLv%。特定のとどめで2ダメージを狙えます |

レギュラーの弓は最大Lv10です。例えばエルフの弓Lv10なら、基本の攻撃率は21%になります。

硬化中の怪獣など、攻撃が無効になる相手や、危険を招く状態を避けることがあります。機械弓も常時2ダメージではなく、通常攻撃と条件付きのとどめを使い分けます。

## 衣服とアクセサリーを選ぶ

衣服には経験値獲得を助けるものがあります。「秘書のスーツ」はアイテムLv%の確率で対象の地上技能経験値を2倍にします。少子化対策は対象外で、地底の戦闘EXPを増やす効果ではありません。

アクセサリーには、資金繰りの収入、資金・食料・資源の容量、怪獣の自然出現率、KARMAなどへ作用するものがあります。**詳しい効果は各アイテムの効果欄で確認してください。**

容量を増やす装備を外すと、保管できる上限も変わります。いっぱいまで蓄えているときは、入替前後の上限に注意しましょう。

## 入手と売却

導入イベント、地上の怪獣討伐、交易場などで入手できます。怪獣を倒せば必ず落ちるわけではなく、残骸の資金・怪獣肉とは別の報酬です。

取引可能なアイテムは交易場へ出品できます。装備中のものは外してから出品し、出品中のものは装備や固定売却に使えません。

| レアリティ | 固定売却の基本価格 |
|---|---:|
| ノービス | 100億円 |
| レギュラー | 500億円 |
| カースド | 1億円 |

固定売却の価格は、アイテムLvに比例して増えるわけではありません。交易場でほかの島へ売る場合は、出品価格と入札によって決まります。

地底の短剣・杖・防具を探している場合は、別のページの[地底装備](/manual/equipment)へ進んでください。
