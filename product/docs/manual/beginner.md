# はじめの一歩

最初の目標は、食料を切らさずに人口を増やし、次の建設に使う資金を得られる島を作ることです。いきなり広い土地や大量の工場を持つ必要はありません。

## ログインして島を登録する

ログイン画面に表示される外部サービスで認証し、島名・島主名・紹介文を登録します。同じ世界に、同じアカウントで二つの島を同時に登録することはできません。同名の島がある場合は別の名前を選んでください。

新しい島には、最初の資金100億円と小麦10,000トンが用意されます。島を作ったら早めに開発計画を入れ、開発を始めましょう。

## まず見る四つの場所

| 場所 | 確認すること |
|---|---|
| 島の情報 | 人口、資金、食料、面積、次の更新時刻 |
| 地図とマスの詳細 | 所有者、地形、施設、人口や施設規模 |
| 開発計画 | 次の更新で何を行うか。先頭の計画から確認 |
| 島のログ | 前の更新で何が成功・失敗し、何が増減したか |

地図は全員で共有しています。見えている土地が、全部自分のものとは限りません。**マス詳細の所有者も確認してください。** 座標には負の数も使われます。

地図のマスは、一行おきに横へ半マスずれて並んでいます。隣接するのは、左右と斜め上下の六方向です。周囲1マスは隣の6マス、周囲2マスまでなら中心を含めて最大19マスになります。

## 開発計画の基本操作

地図で対象マスを選び、実行する計画と必要な数量を選んで登録します。島全体への計画や援助では、マスではなく島を対象にするものもあります。

登録できる計画は最大30件です。順序、対象座標、数量を確認し、不要なものは取り消してください。複数回の整備を予約した場合は、その反復が終わるまで後ろの計画が待つこともあります。

資金や対象の状態は、実行時にも確認されます。登録時に建てられそうでも、その後に資金を使った、土地の所有者が変わった、怪獣や災害で地形が変わった、といった場合は失敗することがあります。

### ターンを使う計画・使わない計画

通常の建設や整備は、ターンを使って一つずつ進めます。地ならし・資金援助・食料援助・領土破棄などには、ターンを使わないものがあります。そうした計画の後には、同じ更新内で後続の計画へ進めます。

**「ターンを使わない」は、登録した瞬間に実行されるという意味ではありません。** 計画欄に入れたものは、更新時に処理されます。

ミサイルには同じターンに組み合わせられる種類があります。詳しくは[ミサイルと怪獣](/manual/advanced)を参照してください。

### 数量は計画によって意味が違う

| 計画 | 数量の意味 |
|---|---|
| 農場・工場・採掘場の整備 | 同じ場所で整備を繰り返す回数 |
| ミサイル | 発射を希望する本数。実際の本数は基地の能力と資金にも制限されます |
| 海での掘削 | 油田探索へ投入する口数。費用と成功率に関係します |
| 資金援助 | 数量×100億円 |
| 食料援助 | 数量×1,000トン |
| 記念碑・派遣怪獣・船 | 種類の選択。建設・派遣する個数ではありません |

一般の数量指定は1～99です。数量を使わない計画もあります。「農場整備10」は、一ターンに10回分をまとめて増設する指定ではありません。

## 最初の島の育て方

### 1．農場を用意する

平地に農場を建てます。農場の規模は、そこで働ける人数です。住民が少なければ、大きな農場でも全規模分は生産できません。

住民5人につき、毎ターン小麦1トン分の食料が必要です。食料の増減を見ながら、人口に合う農業規模を確保しましょう。

### 2．村のための平地を残す

農場に隣接する空いた平地には、村が自然に発生することがあります。村は人口を増やし、町、都市へと発展します。村を建てる専用の計画はありません。

農場の周りを全て別の施設で埋めると、新しい村の場所もなくなります。人口を増やす余地と、台風を防ぐ森の両方を考えて配置してください。

### 3．工場や採掘場で資源を作る

食料が安定したら、工場や採掘場を増やします。工場は平地、採掘場は山へ建設します。農場で働いた後に残る住民が、工場と採掘場へ配分されます。

工場は工業品、採掘場は鉱物を生産します。**生産しただけでは資金になりません。** 資源売却で、蓄える量と売る量を設定してください。

### 4．更新後のログを読む

計画の成功・失敗、生産物の売却、災害や怪獣の被害は島のログで確認します。「何か減った」ときは、対象座標と原因をここで調べましょう。

何も実行できないターンなどには資金繰りが行われ、基本で10億円を得られます。ただし、資金繰りを続ける状態は休眠などにつながります。[島の状態](/manual/faq)も確認してください。

## ターン待ちには秘書と地底へ

秘書の名前が未設定なら、「？？？」の導線から名付けを済ませます。その後「地底」を開き、導入イベントを順に進めましょう。

地底の探索や装備整理は、地上の更新を待たずに行えます。地上の資金と地底のGは別会計です。

## 最初に気を付けること

農場を増やしすぎると、全住民が農業へ回り、工場が動かなくなることがあります。食料を売りすぎれば飢饉になり、土地を広げすぎれば地盤沈下の危険が増えます。

整地や掘削は、既存施設を残す操作ではありません。また、防衛施設へ同じ建設を重ねると自爆します。対象に何があるか確認してから登録してください。

施設を調べるなら[土地と施設](/manual/intermediate)、収支を整えるなら[人口と資源](/manual/economy)へ進んでください。
