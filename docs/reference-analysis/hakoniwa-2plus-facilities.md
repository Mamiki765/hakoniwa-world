# 箱庭諸島2＋ 地形・施設仕様

## セルモデル

各セルは永続値 `kind`, `param`, `owner` と一時値 `flag`, `seaLevel` を持つ（`Land`, `map.h:136-179`）。種別IDと意味は列挙ではなく `static const int`、処理は主に `Map::process` と `Com::exec` の `switch` へ直書きされる。

## 表示上の人口・施設レベル

`Town` の表示分類は、0=平地、1..29=村、30..99=町、100以上=都市（`Land::landValue`, `map.c:1328-1365`）。内部成長上限は200である（`Map::process`, `map.c:343-377`）。

ミサイル基地は経験値 `<20`, `<60`, `<120`, `<200`, `>=200` でレベル1..5、海底基地は `<50`, `<200`, `>=200` で1..3（`Land::getLevel`, `map.c:1377-1397`）。レベルがその基地の1ターン内最大発射数となる（`map.c:438-448`）。

## 主要な地形遷移

- 整地：多くの所有陸地 → `Town(0)`（`command.c:205-245`）。
- 埋立：浅瀬 → 所有荒地。条件により周囲海も浅瀬化。他の海/海底基地 → 浅瀬・中立（`248-303`）。
- 掘削：浅瀬 → 深海、山 → 荒地、その他陸 → 浅瀬・中立。深海では投入額に応じ油田探索（`305-374`）。
- 伐採：森 → `Town(0)`（`376-394`）。
- 施設建設：原則 `Town` または同じ施設から遷移/増設（`Com::buildCommand`, `626-667`）。
- 火災・暴動・地震・津波・ミサイル：対象施設 → 荒地（`map.c:840-982`, `491-630`）。
- 台風：農場/ハリボテ → `Town(0)`（`map.c:967-979`）。
- 流星/巨大隕石/掘削：海化・深海化を含む（`map.c:984-1028,1109-1165`）。
- 噴火：中心→山、隣接は海→浅瀬、浅瀬→荒地、他陸→荒地（`map.c:1030-1073`）。
- 怪獣移動：移動先を怪獣へ、元を荒地へ（`map.c:666-716`）。

## 防衛施設と国境

真防衛施設の効果はミサイル着弾点半径2の迎撃であり（`map.c:479-489`）、国境感化への抵抗値はない。`Map::infLand` は防衛施設を他の通常施設と同様に隣接ownerへ即時変更し得る（`map.c:211-260`）。新作構想の「防壁都市による国境抵抗」は新しいルールである。

## 新施設追加時に変更が必要な箇所

旧設計では少なくとも次を横断して変更する必要がある。

1. 地形ID/param定数：`map.h:136-168`。
2. コマンドID：`command.h:27-61`。
3. 費用表：`command.c:5-35`。
4. 建設条件・遷移：`Com::exec/buildCommand`, `command.c:127-698`。
5. ターン効果：`Map::process`, `map.c:264-739`。
6. 災害対象：`map.c:840-1073`。
7. ミサイル対象：`map.c:419-641`。
8. 広域被害・消滅：`map.c:1109-1190`。
9. 集計：`Land::estimate`, `map.c:1293-1326`。
10. 表示の秘匿・分類：`Land::jsOut/landValue/getLevel`, `map.c:1258-1291,1328-1400`。
11. ブラウザ側表示：`hakow.js`（今回は挙動解析対象外）。

この分散した `switch`/配列設計は、後から資源・施設・研究・熟練度・アイテム効果を追加する新作要件に適さない。新作ではID付き定義、効果コンポーネント、イベントハンドラー、検証可能な遷移規則を分離する必要がある。

## コード上の問題候補

- `SBase` 建設条件は「海以外はだめ」というコメントに対し、`land->kind != Sea && land->kind != SeaDeep` と地形種別をparam定数 `SeaDeep(0)` にも比較する。`Sea` 自体が0なので結果として全ての海paramを許す（`command.c:509-521`; `map.h:139,154`）。深海限定意図か要確認。
- 植林・基地建設を既存の同施設へ再実行すると `buildCommand` の共通flag分岐へ入るが、森・基地のturn処理はそのflagを参照しない（`command.c:626-680`; `Map::process`, `map.c:382-387,411-641`）。費用を消費する無効果操作が意図か要確認。
- 人口0平地の村発生は海際度別 `ratio` を計算するが、実判定は固定20%を使う（`map.c:321-341`）。コメントと実装が不一致。
- コマンド座標のY上限補正で `y` ではなく `x` を書き換える（`command.c:136-142`）。ただし補正前に `getLand(x,y)` を呼び、範囲外なら先にreturnするため、この分岐自体が通常到達しにくい。
