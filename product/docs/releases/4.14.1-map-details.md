# 4.14.1 地図の上限・ピザ屋の収益表示

application **4.14.1**。Rulesetは4.14.0と同じv31を維持する。
PR196をマージ済みのmain（`1d7c5beb6831b6a0983f4706c2be7af631aee820`）を基点とする単独PR。

## 表示

- 既存の地図情報欄とツールチップへ「最大」を追加する。現在値は従来の欄に残す。
- 村・町・都市・海底都市は自然増上限/誘致上限の順。少子化対策の現在Lvを既存の`SecretaryDemographicPolicy`へ渡す。例：Lv14なら`10,700/21,400人`。区切りは半角`/`で、値の欄のtitleと地図ツールチップにだけ順序の短いヒントを付ける。
- 首都は自然増の上限1値。地下都市の現在の補正を既存の`UndergroundFacilityBenefits`から加算する。人口上限は自島だけに表示し、他国の秘書Lvや地下施設を推測できる表示を追加しない。
- 森の樹木数上限は現在Worldの`terrain_quantities`、農場・工場・採掘場の規模上限は既存の`FacilityRankPolicy`と`FacilityCapacityService`から取得する。基本3施設はランク2までの増築上限を表示する。
- 火力発電所は現在設備の発電上限に加え、増築可能な最大設備の発電上限をMW/Tで表示する。ピザ屋は処理量の最大を既存のt/Tで表示する。
- ピザ屋の「収益上限」は現在の規模へ食料・電力が充足した場合の値。`PowerEconomyCalculator::settle`の正規決算値を使い、現在の国全体の在庫配分から得られる実収益とは扱わない。「食料・電力充足時」と値に添える。初期規模の例は16億円/Tで、食料なし・電力なしなら正規決算では0となる。
- 地上ミサイル基地・海底基地は最大経験値到達時に既存LVへ★を添える。数値上限の欄は追加しない。中央銀行・中央穀倉は既存のLv/最大Lv表示を維持する。
- 風力の既存発電範囲、コンデンサの既存容量、上限のない海底油田などへ架空の最大を追加しない。偽装やowner専用情報の可視性を維持する。

増築・収益・人口成長・資源予測の計算とゲームバランスは変更しない。
資源予測は4.14.0の最悪側単一値の表示を維持する。
