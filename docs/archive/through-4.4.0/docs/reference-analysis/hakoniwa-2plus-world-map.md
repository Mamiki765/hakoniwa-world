# 箱庭諸島2＋ 世界マップ仕様

## 共有世界の成立箇所

**確定**：国家ごとの個別マップではない。全国家は、プロセス全体で一つだけ存在する `Map::land` 配列を共有し、一つの `data/map.cgi` へ一括保存する（`Map::land`, `map.c:3`; `Map::alloc`, `map.c:13-16`; `HakoIO::readMapFile/writeMapFile`, `hako_io.c:116-152`）。各セルの `owner` が国家との関係を表す。

国家の `centerX`, `centerY` は共有マップ上の注目中心であり、国家別マップの原点ではない（`info.h:70-86`; `new_island.c:70-82`）。

## サイズと配列

- `worldSize` を縦横の双方に使う正方形である（`Map::alloc`, `map.c:13-16`）。
- 同梱設定は60なので、初期世界ではなく **常に固定60×60** として動く（`config.cgi:43-44`）。設定自体は変更可能だが、実行中の動的拡張はない。
- 座標範囲は `x=0..worldSize-1`, `y=0..worldSize-1`、原点は保存・表示配列の左上と解釈できる（`Map::output/jsOut`, `map.c:27-67`）。
- 配列は行優先で `land[y * worldSize + x]`（`Map::getLand`, `map.c:89-97`）。
- 永続化は `y` 外側、`x` 内側（`Map::input/output`, `map.c:27-47`）。

## 六角形座標

周辺座標は半径0..11の397セル分を `ax[]`, `ay[]` に直書きし、中心行と移動先行の偶奇で `x` を補正する（`map.c:5-10`; `Map::getPoint`, `map.c:69-85`）。これは行をずらすoffset座標による六角形グリッドである。

半径と累積セル数は、0=1、1=7、2=19、3=37、4=61、5=91、6=127、7=169、8=217、9=271、10=331、11=397（`map.c:5-7`）。多くの処理はこの配列の添字範囲で距離を表す。

距離関数も行の偶奇を補正して六角距離を返す（`Map::distance`, `map.c:1200-1224`）。

## 端の扱い

世界はラップしない。範囲外の座標は `(-1,-1)` またはnullとして返す（`Map::getPoint/getLand`, `map.c:69-103`）。ただし用途により次の仮想的な扱いをする。

- 地形数の集計では範囲外を深海として数える（`Map::countAround`, `map.c:105-124`）。
- 中立地判定では範囲外を中立として数える（`Map::countNeutral`, `map.c:126-140`）。
- 実際の書込・セル処理では範囲外をスキップする。

この非対称性により、端や完全な範囲外を新規登録中心として指定しても空地検査を通過し得る。これは意図された仕様とは確定できず、問題候補として扱う（`new_island.c:50-59,84-209`）。

## 海・陸地・国家

地形種別は `Land::Sea` から `Land::Monument` まで12種（`map.h:136-150`）。所有権と地形は独立して保存されるため、次の組合せがある。

- `owner=0`：中立。
- `owner>0`：`Info::islands` の現在順位を参照。
- 通常の陸地は国に所有され得る。
- 深海・浅瀬は通常中立だが、油田は海地形のまま所有者を持つ（`command.c:320-340`; `Map::process`, `map.c:275-290`）。
- 海底基地は海上施設だが所有者を持ち、国土面積からは除外される（`command.c:509-533`; `Land::estimate`, `map.c:1293-1326`）。
- 荒地は所有され得るが、自動国境感化の対象外（`Map::infLand`, `map.c:219-225`）。

## 国ごとの領土判定

`owner` は不変の国家IDではなく、人口順配列の1始まり順位である。`Info::getIsland(owner)` で国家を引く（`Info::getIsland`, `info.c:116-122`）。各ターン末に国家を人口順へ並べ替え、全セルのownerを新順位へ変換する（`Info::sortIslands`, `info.c:41-63`; `Map::changeOwner`, `map.c:1185-1190`; `Land::changeOwner`, `map.c:1368-1374`）。

**新作へ持ち込まない前提**：所有権を可変順位で保存すると、ソートのたび全マップを書き換える必要があり、チャンク保存・部分取得・監査ログに不向きである。不変の国家IDを使うべきである。

## 国境変更

### 自動感化

ターン冒頭、全セルを乱数順に1回ずつ `Map::infLand` へ渡す（`Turn::main`, `turn.c:26-36`; `Turn::makeOrderXY`, `turn.c:174-198`）。対象セルは所有された非中立の地形で、海、荒地、怪獣、海底基地、記念碑を除く（`map.c:211-231`）。

対象セルは隣接6方向からランダムに1セルを選び、その隣接セルが別国所有かつ海・荒地・怪獣・海底基地でなければ、対象セルのownerを隣国へ変更する（`Map::infLand`, `map.c:233-260`）。施設の耐久、人口、軍事力、国家総人口は判定に使わない。

処理順はランダムで、変更結果が同じフェイズ中の後続セルへ即時反映される。したがって確率的かつ順序依存の国境伝播である。

### 領土拡張コマンド

`Widen` は、対象の隣に自国の「荒地以外の陸地」があり、対象が自国領でなく、他国の荒地以外でもなく、海・怪獣・海底基地でもない場合にownerを自国へ変更する（`Com::exec`, `command.c:396-436`; `Map::nearLand2`, `map.c:160-176`）。コストは100（`command.c:5-35`）。

### 国家消滅

国家が放棄または人口0以下で消滅すると、その国の全所有セルを深海1/3、浅瀬2/3へ変え、ownerを0にする（`turn.c:93-121`; `Map::deleteIslands`, `map.c:1168-1183`）。歴史的領土や中立陸としては残らない。

## 中立地

中立は専用地形ではなく `owner=0` で表す（`map.h:171-173`; `Map::countNeutral`, `map.c:126-140`）。自動感化は中立セルからも中立セルへも働かず、取得には `Widen` 等の明示コマンドが必要になる。新規国家の周囲5hexは全セルのownerが0であることだけを要求し、地形種類は問わない（`new_island.c:50-59`）。

## マップが満杯の場合

登録時の明示的な上限は国家数 `totalNumber >= maxNumber` と、利用者が指定した半径5の91セルが全て中立かどうかだけである（`new_island.c:7-12,50-59`）。空き位置の探索、最適配置、世界拡張はない。

したがって、国家数が上限未満でも適切な空き領域がなければ登録失敗する。逆に端の範囲外を中立として数えるため、実質的な空きが91セル未満でも検査を通る可能性がある。

## 世界拡張

**確定**：実行中の世界拡張機能はない。配列確保、全走査、保存行数、乱数順列、災害座標の全てが単一の `worldSize × worldSize` を前提とする（`Map::alloc`, `map.c:13-16`; `Map::input/output`, `map.c:27-47`; `Turn::makeOrderXY`, `turn.c:174-198`; `Map::globalDisaster`, `map.c:742-819`）。設定変更によるサイズ変更にも旧 `map.cgi` の移行処理はない。

## 動的拡張で不要になる旧前提

新作で「既存座標を動かさず、必要方向へチャンク追加」を採用する場合、次を廃止または抽象化する必要がある。

- `worldSize` 一値で縦横と境界を兼ねること。
- 全セルを連続配列へ置き、毎ターン必ず全走査すること。
- 1ファイルの行番号がそのままY座標になること。
- 範囲外を永久的な深海/中立とみなすこと。
- 災害中心を `0..worldSize-1` 周辺からだけ選ぶこと。
- owner順位変更のたび全セルを書き換えること。
- 半径0..11だけを静的配列へ列挙すること。
- 全マップを常にJavaScriptへ送ること（`Map::jsOut`, `map.c:50-67`）。

六角距離、共有世界、owner=0の中立概念、コマンドとターンのフェイズ分離は、座標・保存方式から切り離せば継承候補になる。
