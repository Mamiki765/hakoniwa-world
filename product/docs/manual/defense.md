# 怪獣と防衛

島が大きくなると、怪獣が現れるようになります。人口が多いほど、手強い怪獣も現れます。

## 怪獣が出たら

まず地図で怪獣のマスを選び、「マスの詳細」で種類・残りHP・特性を確かめます。

- 怪獣はターンごとに動き回り、踏んだ施設を壊します
- 種類によって、動く速さ、硬くなってダメージを受けないターン、倒し方の注意が違います。詳しくはマスの詳細の説明を見てください
- 自分の島だけでなく、ほかの島の怪獣を倒すこともできます

怪獣を倒すと、資金と怪獣肉が手に入ります。肉は怪獣がいた島へ届きます。秘書のアイテムが見つかることもあります。

## ミサイル

ミサイル基地（または海底基地）があれば、ミサイル発射のコマンドで狙ったマスへ撃てます。数量は撃ちたい本数です。

| 種類 | 特徴 |
|---|---|
| ミサイル | 安いが、狙った場所の周り2マスに散らばります |
| PPミサイル | 周り1マスに散らばります |
| SPPミサイル | 狙った場所に正確に落ちます。高価です |
| 陸地破壊弾 | 地形そのものをえぐります |

費用は[コマンドの索引](/manual/commands)にあります。

**指定した本数が全部撃てるとは限りません。** 1ターンに撃てる本数は基地の力で決まり、資金が足りなければそこで止まります。基地は撃って経験を積むと、撃てる本数が増えます。首都地下の地底ミサイル基地でも本数を増やせます。

## 防衛施設

防衛施設は、周り2マスに飛んできたミサイルを迎撃します。自分のミサイルも迎撃するので、**防衛施設の近くの怪獣にはミサイルが届かない**ことがあります。怪獣が倒せないときは、近くの防衛施設を確かめてください。

- 自分の防衛施設にもう一度防衛施設を建てると、自爆して周りにも被害を出します
- 怪獣が防衛施設を踏んだときも自爆します
- ハリボテは見た目だけの防衛施設で、迎撃はしません

## 秘書と船も戦える

秘書が弓を装備していると、ときどき怪獣を射ます。戦艦を持っていれば、近くの怪獣や海賊船を自動で撃ちます（[海と船](/manual/sea)）。

## 他島への攻撃とKARMA

ほかの島へミサイルを撃って施設や土地を壊すと、KARMAという値が上がります。KARMAが高すぎると、箱庭連合に目を付けられ、島が危険にさらされます。

KARMAは時間がたつと少しずつ下がり、ほかの島の怪獣を倒しても下がります。怪獣を狙ったつもりでも、外れたミサイルが他島の施設を壊せばKARMAは上がるので注意しましょう。

## 怪獣派遣

怪獣派遣のコマンドで、ほかの島へ機械の怪獣を送り込めます。
