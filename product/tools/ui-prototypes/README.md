# UI試作品

正式画面を置き換える前に、配置と操作の流れを比べるための独立した試作品を置く。
本体の`resources/js`・Vite・Laravelには依存せず、buildも不要。`index.html`が各試作への入口。

## surface — 地上開発画面

`surface/index.html`をブラウザで直接開くか、任意の静的serverで配信する。
上部のバーで案A（帳簿）・案B（俯瞰）・案C（片手）、スマホ幅、状態（読み込み中・通信エラー・空・資金不足）、配色を切り替える。URLの`#a` `#b` `#c`でも案を選べる。

- データは`surface/data.js`の固定fixture。コマンドの名称・費用・ターン消費はRuleset v36から転記し、形は`resources/js/types.ts`に寄せた。島の配置・資源量・ログ文面は架空。
- 計画の追加・並べ替え・取消はページ内の配列を書き換えるだけで、APIを呼ばない。
- タイルは`surface/tiles.js`がcanvasで描く仮のドット絵。本番の地形・施設画像はrepository外にあるため使っていない。
- 計画の「第Nターンごろ」は目安。実行できなかった計画があると後ろが前に詰まる。数え方は、ターンを使う計画を1件1ターン、農場・工場・採掘場の整備を数量ぶんのターンとして数えた目安。serverの実際の進行と一致するかは未確認。
- コマンドの分類（整備・建設・軍事・輝石・島全体）は試作で付けたもの。Rulesetには無い。

## underground-battle — 地底の戦闘ログ

`underground-battle/index.html`を開く。上部のバーで場面（1対1・4対1ボス・4対3）を切り替える。URLの`#duel` `#boss` `#party`でも選べる。

- 1対1と多人数を同じ部品で描く。陣営の人数でカードの大きさだけが変わる。
- 「読む」はログのスクロール位置に戦況カードのHPなどが追従する。「再生」は1行動ずつ進み、速さ・1行動送り・ラウンド送り・結果へのジャンプができる。
- 「要点」は会心・覚醒・予告・撃破だけを出し、ラウンド見出しに与えた／受けた／回復の合計を出す。「すべて」で全行動を出す。
- 連続攻撃と全体攻撃は1行にまとめ、内訳を下に並べる。
- 戦闘データは`underground-battle/sim.js`の簡易計算で、本物の戦闘計算ではない。行の形は`party-presentation`の`rounds[].actions`に寄せ、各行に直後の全員の状態を持たせた。敵と地名はconfigの名称、味方の名前と技名は仮。
- 顔アイコンはcanvasで描く仮のドット絵。

## underground — 地底（ホーム・冒険・キャラクター・ショップ・交流場）

`underground/index.html`を開く。URLの`#home` `#adventure` `#character-vault` `#shop-bank` `#exchange` `#event`などで画面を選べる。配色は`underground-battle/style.css`を共有する。

- 組み方はソシャゲのホーム画面。拠点の画面は上に所持金、下にメニューを固定し、内容が少なくてもメニューは下端に残る。イベントシーンと戦闘の入口は枠（所持金とメニュー）を消して全面に出す。
- ホーム: 立ち絵と背景が全面。左上に秘書の状態、その下に「今やれること」の知らせ（STPの残り、歪んだ輝石の受取、保管庫の残り）、下にパーティーのHPと行き先・出発ボタン。
- 冒険: 探索・試練・秘密の場所。行き先の一覧と詳細、スキップチケットの回数選択、鍵や歪んだ輝石の必要数。
- キャラクター: 能力、STP配分（決めるまでやり直せる）、装備・保管庫。
- 保管庫: 「残す物を決めて、ほかを売る」作り。分類を選び、残したいエンチャント（共鳴結晶は効果）・装備Lv以上・品質以上・レア度以上を必要な分だけ入れると、「共鳴結晶は、「攻撃技強化」と「単体攻撃強化」を全部持つ物を残す。それ以外を売ります。6個」のように文と個数が出る。入れた条件は全部満たす物だけ残る（and）。エンチャントを2つ以上選んだときだけ「全部持つ／どれか持つ」を切り替えられ、同じエンチャントを2つ持つ指定もできる。一覧では売る物を上に並べ、☆で保護すると条件に関係なく残る。装備中の物と売れない一点物（ユニーク）は常に残る。下の帯で個数と合計額を確かめてから売る。
- STP配分: ＋と−は押しっぱなしで加速する。数字の直接入力もできる。残りを超える入力は残りまでに丸める。
- ショップ: 歪んだ輝石の受取・購入、装備を買う、銀行（預ける・下ろす）。「案内人と話す」は枠なしのイベントシーンになる。
- 交流場: パーティーの入れ替え。
- そのほか（`ug2.js`）: 戦闘履歴（勝てなかった戦いだけに絞れる）、スキル・覚醒（系統ごとの技の並び、取得、技の枠、覚醒の台詞と覚醒技）、戦法（「もし〜なら〜を使う」の行を並べ替え・追加・削除。おまかせ／自分で決める）、魔石研磨（いまとみがいたあとの比較）、不動産（買う前の確認つき）、行商人との会話、冒険日誌、回想（枠なしのイベントシーンで読む）、トロフィー棚。
- 上の画面の技の名前・覚醒技・戦法の条件の種類・値段・戦績・物語の文面は仮。現行の戦法は条件の種類や上限をserverが配る（catalog）ので、実装時はそれに合わせる。
- 未作成: 異世界の戦い、力試し、導入の物語と案内人の名付け、装備の付け替え操作。
- 現行APIとの差: 現行の一括売却（`bulk-sell/preview`）は装備Lv以下・品質以下・レア度・分類・武器の種類という売る側の条件。試作は残す側の条件で、エンチャントの有無と個数、★の保護を使う。これらは現行APIに無いので、採用するならAPIの追加が要る。保護は画面だけでなくserver側でも売却を拒否する必要がある。エンチャントの値の下限と、条件の保存は入れていない。
- 立ち絵と背景は破線の枠だけ。地名・敵・能力名・分類とレア度の呼び名・エンチャント名・共鳴結晶の効果名は本体の名称。人名・数値・装備名・台詞・報酬は仮。

## top — TOPと島一覧

`top/index.html`を開く。配色と基本部品は`surface/style.css`を共有する。

- PCは左に島一覧の表（列見出しで並べ替え、島名・島主名で絞り込み）、右にターン状況・お知らせ・世界の出来事。
- スマホは1列で、島一覧は表から行カードに変わる。並べ替えに選んだ項目を右に大きく出し、残りを小さく並べる。順番はターン→島一覧→お知らせ→出来事。
- 状態の切り替え: ログイン済み、未ログイン、ターン更新の遅れ、島がまだない。
- 島名・島主名・秘書名・数値・ニュースの文面はすべて架空。列の構成だけ現行の島一覧に合わせた。

## secretary — 秘書ページ

`secretary/index.html`を開く。配色と基本部品は`surface/style.css`を共有する。

- PCは左に立ち絵を固定し、右に名前・地上と地底の数値・タブ。スマホは立ち絵（バスト切り抜き）を上に置く。全身／バストを切り替えられる。
- 紹介（経歴の書き直し、地上の装備）、スキル（内政スキル11種のLvと次のLvまで）、装備（地上5枠の付け替え、地底6枠）を作ってある。倉庫・実績・設定は未作成の案内だけ。
- 「見ている人」で自分用・公開用・画像なしで地底未到達の3つを切り替える。公開用では編集と持ち主だけのタブを出さない。
- 項目は`types.ts`の`SecretaryProfile`にあるもの、スキル名はRuleset v36の名称。秘書の名前・経歴・数値・装備名・効果や育て方の説明文は仮。

## site — 全体ナビと地上の周辺画面

`site/index.html`を開く。URLの`#visit` `#trade` `#tools-sale` `#options` `#inquiry`などで画面を選べる。配色と基本部品は`surface/style.css`を共有し、観光の地図は`surface/data.js`と`tiles.js`を使う。

- 全体ナビ: 上に1本。主な行き先（TOP・自島・観光・交易場・秘書・地底）を文字で並べ、通知とメニューを右に寄せる。未ログイン・島なしでは行き先を減らす。地底にいるときは細い帯だけにし、地底側の下端メニューと二重にしない。TOP・自島・秘書・地底は別の試作にあるので、ここでは案内だけ出る。
- 観光: 他の島を見る画面。公開の数値、地図（計画は入れられない）、選んだマスの公開情報、伝言板、公開島ログ。持ち主にしか見えない情報は落とす（ミサイル基地は森に見える、施設の経験値は出ない、資金は大まかな額、秘密通信は「あり」だけ、ログの収支と秘密通信は出ない）。
- 交易場: 出品一覧と入札、自分の出品と取り下げ、出品フォーム。入札の状態（未入札・最高額・上回られた・自分の出品）を出し分ける。
- 島の道具: 資源の売り方（全部売る／この量を残す／上限まで貯める）、船の向き、伝言板、地下の施設枠、デイリークエスト、配布倉庫、島を作る。
- そのほか: お知らせ（一覧と本文）、オプション（配色、画像の表示、プロフィール、島を休ませる・手放す）、アカウント、お問い合わせ、マニュアルの目次、読み込み中・エラーの見本。
- 未作成: 記念碑のデザイン、お知らせの作成・編集（管理者向け）、マニュアル本文。
- 島名・人名・数値・文面・相場は架空。項目は現行の画面にあるものを使った。
