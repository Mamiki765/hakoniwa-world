### 本プロジェクトの採用方針

- 現段階では非商用のローカル参考・開発・動作確認に限る。
- ソースと画像はいずれもGitへ収録しない。
- 原GIFは、箱庭諸島2＋に対応する既存地形・施設・怪獣等の新作UI表示に使用する。Git外のディレクトリへ原名・原形式のまま配置し、実行環境から読み取り専用で参照する。
- 原作にない首都や新施設へ原GIFを流用せず、別素材またはplaceholderを使用する。
- 原GIFが未配置、読取不能、対応未確認の場合は代替表示を使い、推測で別のdefinitionへ割り当てない。
- 「画像を直接コピーしない」は、画像バイナリをGit管理領域へ収録しない、新作独自素材として再配布しない、出典不明素材を転用しないという境界を指す。外部配置した原GIFのゲーム実行時利用は禁止しない。
- 公開サーバーでの利用前に、原文、後年の説明、アーカイブ、権利者表示、58個への適用範囲を改めて確認する。確認事項を残したまま利用可能性を法的に断定しない。
- 配布元へのリンクと作者表示を維持する。
- 論理キー、原ファイル名対応、配置・fallback契約は`docs/assets/tile-asset-mapping.md`に記録する。

この記録は上記の権利評価・再配布方針を変更しない。GIFはGit、`product/public`、container imageへ収録せず、production operatorがGit外のread-only asset directoryへ原名・原形式で配置する。applicationは既存tile resolver経路だけを使い、不足時はCSS fallbackを返す。加工、再描画、AI生成、形式変換、無断の別画像代用を行わない。
