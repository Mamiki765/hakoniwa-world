# 4.1.0 案内人との決闘

## Owner決定と変更範囲

2026-09-14のOwner依頼・添付`hakoniwa-4.1.0-rika-duel-owner-spec.md`を起点とする。添付文書の提案・未指定事項はそのまま確定事項とせず、その後のOwner「キミの提案通りで」で以下を採用した。添付時点のHP1001254／毎round10000回復は、Owner指定のHP351400／毎round1254回復へ置き換える。敗北時の4行も同日のOwner追加文言をそのまま用いる。

- 輝きの王国解禁後、案内人の部屋→真剣な話→勝負を挑む。確認・取消、初勝利後の再戦会話、ソロ再戦専用会話を用意する。初勝利後のソロでは専用会話を優先する。
- 無料。通常探索の待ち時間を消費せず、HP・MP・覚醒を通常の進行へ書き戻さない。EXP・G・鍵・通常drop・貸出参加回数・日課進行は増減しない。進行中の試練とスキル再設定未完了時は挑戦できない。
- 自分の秘書1人、または確定済みのレンタルPTで戦う。レンタルPTを編集せず、決闘だけ一人で挑める。女王は常に1体で人数・Lv・ILによる補正はない。
- 全参加者は、HP0・覚醒ゲージ不足・覚醒未解禁でも開幕に全回復して強制覚醒する。味方の通常行動に先行して女王が奥義を使う。その後の味方奥義は既存AIに従う。
- 25%以下へ初めて到達したことを保持し、そのaction終了後に2回目の奥義が割り込む。同じ多段actionの残りhitでも、それまではHP1で耐える。2回目の実行開始後は保護せず、実ダメージで勝敗を決める。100 round終了時の未決着は敗北扱い。
- 初勝利はLeader自身のSecretaryごと。魔剣グラムは長剣・ユニーク・IL1254の固定記念品1個で、装備不可・売却不可・所持効果なし。能力名は説明だけ表示する。満杯でも一度限りの報酬を失わせず付与するため、この付与で保管数が通常容量を1個超える場合がある。通常の購入・dropの容量制限は維持する。

## Release境界

Owner追加依頼として、宝物庫の装備中itemを武器→防具→アクセサリー1→2→3の順で先頭に置く。未装備itemには入手の新しい順／古い順・Item Lvの高い順・種類順を用意する。全所持itemのcanonical定義を解決してから並べ替え・ページ分割を行い、固定装備と生成装備の双方でページをまたぐ順序を揃える。この表示変更にmigrationやRuleset追加はない。

- 4.0.0 main `319ea20165a7e7e111749c4f5d9f337f1045a1a0`をbaselineとする。
- `release/4.1.0`にはPR #5の障壁表示hotfixも含める。application versionは4.1.0。
- 新migrationは`2026_09_14_000000_add_guide_duel`の1本だけ。既存battle／content clear progressのcheck constraintへ`guide_duel`を追加する。既存データのreset・再解釈・過去migrationの書換えは行わない。downは履歴保護のため拒否する。
- Undergroundの新content identityは`secretary-underground-guide-duel-v1`。通常combat identity `secretary-underground-alpha-v5`、Surface Ruleset `hakoniwa-2s-plus-v25`は維持する。Surface immutable snapshotへの変更はない。
- merge・deploy・production migrationはこの開発作業の対象外。
