# ver 1.4.0 announcement

ver 1.4.0 deploy後、既存のお知らせ管理画面から次のplayer-facing announcementを1件作成する。announcementはoperator-authored production dataであるため、migration、seeder、deploy scriptから自動作成・上書きしない。

## Title

```text
ver 1.4.0
```

## Body

```text
・島の周辺へ領土を広げる「領土拡張」と、ターン更新時の領地感化を追加しました。領土の移動は活動中の島の間だけで起こり、首都周辺は保護されます。
・島の伝言板を追加しました。観光客には固定の表示IDが付き、投稿には10秒の間隔があります。島主は100億円で相手だけに届く秘密通信も送れます。
・怪獣、ミサイル、災害、コマンド、援助、受賞などの出来事を、全体ニュース・公開ログ・島主専用ログに分けて読みやすくしました。
・食料が倉庫上限を超えたときは、売却単位ごとに資金上限まで自動売却し、売れなかった超過分だけを破棄するよう修正しました。
・スマートフォンの島画面を、コマンド・地図・開発計画の3領域へ移動しやすい構成に改善しました。送信状態と修正可能なエラー理由も簡潔に表示します。
・データ移行、ターン更新、コマンド送信まわりの安全性と安定性を改善しました。
```

作成後はpublic lobbyの最新お知らせとお知らせ詳細でtitle、改行、本文を確認する。同じrelease announcementが既に存在する場合は重複作成せず、既存記事を確認する。
