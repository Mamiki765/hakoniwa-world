# 4.11.1 資源予測・ピザ屋・秘書

application **4.11.1** / Ruleset **hakoniwa-2s-plus-v29**。
4.11.0を取り込んだmain `a5149d61333dce81b821630361208359bdf0ba1f`からの修正。

## 変更

- 資源予測の食料行は「食料（小麦換算）」。電力行のセルはMWを付けず、数値・範囲・増減符号を表示する。表の下にある食料・電力・燃料・ピザの説明文を削除する。
- ピザ屋の金銭維持費を施設ごとの1億円/Tから0にする。残高0でも食料と電力があれば稼働する。食料・電力の消費、供給不足時の稼働制限、売上計算は共通の決算・予測基盤を維持する。他施設の維持費は変更しない。
- 「省エネ」を「省エネ研究」に変更する。全10スキルの効果と経験値条件を分け、条件は効果の下へ短文で表示する。小さな文字と既存のmuted色を使う。
- 最終防衛ラインの条件は迎撃を含む「飛来」、少子化対策は「過去最大人口を更新する（経験値補正無効）」とする。経験値の獲得処理・成長曲線を変更しない。
- 船舶運用と海軍は現在もレベルによる効果が未実装。移動成功・軍艦の命中による経験値条件を表示し、効果表示は従来の「準備中」「効果なし」を維持する。

## 前進移行

本番で使われたv28のpayload、定義、既存migrationファイルを変更しない。
v29はv28から世代・金銭維持費・省エネ研究の名称だけを変更した設定。
追加migration `2026_10_04_000000_publish_pizzeria_maintenance_removal_v29`はWorldをロックし、
未解決の本番Turnがあれば停止する。現在のWorldと同一内容の怪獣・討伐記録・予約地上コマンドを
v29定義へ接続し、資産・蓄電残量・秘書XP・要求受付時のRuleset・Turn履歴を保持する。
地下施設と船の保存時Rulesetは変更しない。再実行で進行をリセットしない。

新規構築では既存v28 migrationも実行されるため、旧移行処理は設定のcurrentに依存させず、
本番v28の完全なチェックサムが一致したsnapshotだけを既存の発行処理へ渡す。
通常のauthoring/publicationはcurrentだけを検証し、変更されたv28の再発行は拒否する。
v27→v28、v28→v29、新規構築をそれぞれ検証する。
