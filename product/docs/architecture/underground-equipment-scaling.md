# 地底装備の倍率とrating

4.6第一弾の現行計算契約。保存済み装備のroll・品質・研磨値・identityは変更せず、装備解決時に投影する。計算の実装は`UndergroundEquipmentScaling`、集計は`UndergroundEquipmentCatalog`と`UndergroundEquipmentLoadoutResolver`を正本とする。

## 倍率と解決

`S(L)=1.1^(max(0,L-200)/10)`を整数bpsへ四捨五入する。武器力`W=S(武器IL)`、防具のHP倍率`A=S(防具IL)`。防具未装備の`A`は1。ratingの必要値は`S(max(200,min(武器IL,防具IL)))`で、防具未装備はIL200相当とする。生成可能ILは220まで。旧武器加算値を戦闘内に保持し、表示上の「武器力」は`W`を指す。

通常7種と共鳴ランダム7種の割合affixは、保存済み基準bpsに品の`S(IL)`を掛けてratingにする。100 ratingを基準の1 percentage pointとし、同一targetのratingを合算した後、必要値倍率で割って実効bpsへ四捨五入する。保存modifiersには既にaffix分が含まれるため、固定由来分と分離してから換算する。エクスカリバーの物理・魔法・治癒・MP補正もrating扱い。共鳴固有の範囲攻撃補正、衝撃波の確率・威力、再生2%は固定のまま。防御行動強化の実効減算は合計90%を上限とし、既存の別系統のguard合成上限を変えない。

攻撃の能力・旧武器加算・固定量由来出力、能力・固定量由来の回復と障壁、独立反撃の出力へ`W`を一度適用する。衝撃波の実ダメージもこの攻撃経路で一度伸びるが、固有の発動率・威力係数へ再適用しない。対象最大HPの割合、反映済みダメージを元にした吸収へ再適用しない。最大HPは、通常計算から各品の最大HPアップaffixを除いて`A`を一度掛け、各affixにはその品の`S(IL)`を一度掛けた値を足す。物防・魔防は`A`で拡大しない。着脱時の現在HP・覚醒のHP更新は既存契約のまま。

研磨は固定能力の1段階30%、基準割合値の1段階10bps、費用と+5上限を維持する。ランダムaffixの研磨後基準値をratingへ解決し、固有固定%は固定のまま加算する。旧generator payloadを再抽選せず、現行・旧世代とも同じ投影を使う。貸出は同期済みの各部位ILでこの集計を行い、貸出元原本を変更しない。戦闘・Trial manifestのidentityは意味変更に合わせて新世代へ進め、過去結果は再計算しない。
