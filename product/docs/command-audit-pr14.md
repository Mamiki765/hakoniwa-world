# PR #14 non-combat command audit

## Scope and evidence

This audit was completed before PR #14 implementation changes. It covers every enabled command in the `roadmap-pr11-v1` ruleset, the generic command catalog and queue UI, queue-time and TurnRunner-time validation, execution effects, audit/player logs, tests, project decisions, and read-only legacy behavior references. Combat commands are not declared in this catalog and are outside this audit.

The canonical coordinate contract is ADR-0003 (`x`/`y`, directions 0 through 5, and nonexistent out-of-bounds neighbors). Legacy behavior was used only where it did not conflict with that decision or an explicit current rule.

## PR-sized follow-up order

1. PR #14: reclaim semantics and deep-sea oil search in the terrain/resource executor. This document records the completed boundary.
2. CMD-02 PR: decide and implement the deferred land-level earthquake check/side effect at its design gate. It must not be folded into PR #14.
3. Oil lifecycle PR: define and implement per-turn oil income, depletion probability, depletion terrain/facility result, and their player logs in `process_cells`. Search and discovery are complete in PR #14; lifecycle processing is a different executor.
4. Future command-catalog PRs: only after their roadmap/design gates, declare currently metadata-only future commands such as facility-specific expansion commands. They are not active command definitions today.

Disasters, monsters, missiles, sanctions, cron, TurnRunner operations, and broad UI changes remain outside this sequence unless separately approved.
