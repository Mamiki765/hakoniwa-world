# UI試作品

正式画面を置き換える前に、配置と操作の流れを比べるための独立した試作品を置く。
本体の`resources/js`・Vite・Laravelには依存せず、buildも不要。

## surface — 地上開発画面

`surface/index.html`をブラウザで直接開くか、任意の静的serverで配信する。
上部のバーで案A（帳簿）・案B（俯瞰）・案C（片手）、スマホ幅、状態（読み込み中・通信エラー・空・資金不足）、配色を切り替える。URLの`#a` `#b` `#c`でも案を選べる。

- データは`surface/data.js`の固定fixture。コマンドの名称・費用・ターン消費はRuleset v36から転記し、形は`resources/js/types.ts`に寄せた。島の配置・資源量・ログ文面は架空。
- 計画の追加・並べ替え・取消はページ内の配列を書き換えるだけで、APIを呼ばない。
- タイルは`surface/tiles.js`がcanvasで描く仮のドット絵。本番の地形・施設画像はrepository外にあるため使っていない。
- 計画の「第Nターン」は、ターンを使う計画を1件1ターン、農場・工場・採掘場の整備を数量ぶんのターンとして数えた目安。serverの実際の進行と一致するかは未確認。
- コマンドの分類（整備・建設・軍事・輝石・島全体）は試作で付けたもの。Rulesetには無い。

## underground-battle — 地底の戦闘ログ

`underground-battle/index.html`を開く。上部のバーで場面（1対1・4対1ボス・4対3）を切り替える。URLの`#duel` `#boss` `#party`でも選べる。

- 1対1と多人数を同じ部品で描く。陣営の人数でカードの大きさだけが変わる。
- 「読む」はログのスクロール位置に戦況カードのHPなどが追従する。「再生」は1行動ずつ進み、速さ・1行動送り・ラウンド送り・結果へのジャンプができる。
- 「要点」は会心・覚醒・予告・撃破だけを出し、ラウンド見出しに与えた／受けた／回復の合計を出す。「すべて」で全行動を出す。
- 連続攻撃と全体攻撃は1行にまとめ、内訳を下に並べる。
- 戦闘データは`underground-battle/sim.js`の簡易計算で、本物の戦闘計算ではない。行の形は`party-presentation`の`rounds[].actions`に寄せ、各行に直後の全員の状態を持たせた。敵と地名はconfigの名称、味方の名前と技名は仮。
- 顔アイコンはcanvasで描く仮のドット絵。

## underground-home — 地底のホーム・行き先選び・店

`underground-home/index.html`を開く。URLの`#home` `#adventure` `#shop`で画面を選べる。配色と窓枠は`underground-battle/style.css`を共有する。

- PCは左にコマンド窓、スマホは下端に6項目のメニュー。ホーム・冒険・店だけ作ってあり、秘書・交流・別荘は未作成の案内だけが出る。
- ホーム: 場面（背景と立ち絵の枠）、自分の秘書の状態、案内人のひとこと、パーティー、次の冒険と出発ボタン。出発後は待ち時間の秒数がボタンに出る。
- 冒険: 探索・試練・秘密の場所のタブ、行き先の一覧と詳細、スキップチケットの回数選択。未解禁の行き先は条件だけを出す。
- 店: 案内人の立ち絵枠と会話、分類タブつきの商品表。手持ち不足・未解禁・所持済みを出し分ける。
- 立ち絵と背景は破線の枠だけ。`resources/scene-assets`の画像は加工禁止・権利表記つきの素材なので、試作には入れていない。
- 地名と敵の名前はconfigの名称。レベル・所持金・商品・台詞・スキップの報酬は仮。

## top — TOPと島一覧

`top/index.html`を開く。配色と基本部品は`surface/style.css`を共有する。

- PCは左に島一覧の表（列見出しで並べ替え、島名・島主名で絞り込み）、右にターン状況・お知らせ・世界の出来事。
- スマホは1列で、島一覧は表から行カードに変わる。並べ替えに選んだ項目を右に大きく出し、残りを小さく並べる。順番はターン→島一覧→お知らせ→出来事。
- 状態の切り替え: ログイン済み、未ログイン、ターン更新の遅れ、島がまだない。
- 島名・島主名・秘書名・数値・ニュースの文面はすべて架空。列の構成だけ現行の島一覧に合わせた。
