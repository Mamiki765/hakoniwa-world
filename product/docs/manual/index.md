# 箱庭諸島２S＋マニュアル

## 箱庭諸島とは

箱庭諸島２S＋は、小さな島を発展させていく国造りゲームです。

島を開発し、人口を増やし、農業や工業を発展させながら、自分だけの島を作り上げていきます。一方で、島の発展には災害や怪獣などの危険もあります。食料と資金に気を配り、長く繁栄する島を目指しましょう。

## 読み進め方

- [初級編](/manual/beginner)：島を作ってから最初に覚えたい人口、食料、資源、施設
- [中級編](/manual/intermediate)：特殊施設、開発計画、ミサイル、怪獣
- [上級編](/manual/advanced)：ターンの流れ、災害、長期的な島作り

初めて遊ぶ場合は、初級編の「最初の進め方」と「食料と資源」から読むのがおすすめです。

## 困ったときの基本方針

- 食料は余裕を持って備蓄する
- 資金不足にならないようにする
- 災害に備えて施設を分散する
- 怪獣は早めに対処する
- 一度に広げすぎず、長く続ける

あなたの島を、世界に一つだけの島へ発展させましょう。
