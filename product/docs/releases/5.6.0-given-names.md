# 5.6.0 船と首都の名前

Owner依頼（2026-10-19）。プレイヤー要望「船一覧が船種＋座標なので、どれがどれか分からない」を受け、自国の船と首都へ任意の名前をつけられるようにする。載せ先は `release/5.6.0`。

## 変更する挙動

- 船（自国の現役船）と首都に、それぞれ1つの名前を任意でつけられる。未設定が既定で、未設定の表示・ログ文言は従来と完全に同じ。
- 名前は1〜16文字（Unicodeコードポイント数）。前後の空白は除き、空なら名前を外す。改行・制御文字・書式文字（`NationProfileText::SINGLE_LINE_PATTERN`）は拒否する。重複は許す。
- 船は船一覧の各行から付け替える（`PATCH /api/v1/nations/{nation}/ships/{ship}/name`、`name: string|null`）。島主のみ。休止・復興中も変更できる（進路変更とは違い、ターン処理へ影響しないため）。ターンも計画枠も使わない。
- 首都はオプションのプロフィール欄（`PATCH /api/v1/nations/{nation}/profile` の `capital_name`）。省略時は維持する。
- 表示: 名前があるときは名前を主に、船種（または「首都」）と座標を小さく添える（船一覧・マス情報・地図のツールチップ・目的地の船選択）。地図の名前は他の島の閲覧者にも見える。首都名は本物の首都マスにだけ出し、偽装中の施設には出さない。
- ログ: 船のイベント（建造以外の到着・損傷・沈没など）と首都のイベント（遷都・災害被害）は、その時点の名前を記録し「漁船「エスポワール」」「首都「ルミナ」」の形で出す。公開ログに出るのは既に公開している船の沈没・遷都・首都被害だけで、新しく公開される情報は名前そのもののみ。過去ログは書き換えない。

## 分類と版

名前は表示専用のプレイヤー入力で、移動・戦闘・RNG・順序に入らない。Ruleset は変更しない（版上げなし）。同じ版・同じシードのターン結果は、名前を含むログ文言以外は変わらない。

## 移行

forward migration `2026_10_19_000000_add_ship_and_capital_given_names.php` で `ships.custom_name varchar(16)` と `nations.capital_name varchar(16)` を nullable で末尾に追加する。既存行はすべて NULL（未設定）。

`CurrentDatabaseBaseline` は、Ecopo と同じく追加列を全体の構造fingerprintから外し、型・NULL可・既定値なし・照合順序を個別に照合する（production の列順に依存しない）。Ecopo と遷都履歴の「末尾列」照合は `capital_name` を除いて数える。downは提供しない。
