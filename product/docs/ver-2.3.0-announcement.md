## Title

```text
ver 2.3.0
```

## Body

```text
・秘書の5つの装備スロットで、倉庫のアイテムを装備したり外したりできるようになりました。効果を発揮するのは装備中のアイテムだけです。
・古びた弓は、毎ターン通常の怪獣行動が始まる前に、10%の確率で自領の地上にいる怪獣へ1ダメージを与えます。すでに配布済みの初期装備も、装備中なら更新後のターンから効果を発揮します。
・指輪は、装備中のレベル合計と同じ億円を、通常の資金繰りと自動の資金繰りへ追加します。現在、指輪の通常の入手経路はありません。
・海上に出現して海を移動する「あおいのら」を追加しました。中立海上で通常撃破すると、撃破者が残骸価値1,200億円を受け取ります。
・「メカいのら零式」を追加しました。怪獣派遣はメカいのら3,000億円とメカいのら零式9,999億円から選べます。零式はHP1になると核爆発を起こします。
・怪獣一覧を更新し、怪獣ごとのHP、出現方法、残骸価値、基地経験値、特殊能力を確認できるようにしました。
・更新時のデータ移行では、既存の島、開発計画、怪獣、撃破記録、秘書、装備、倉庫を維持します。
```
