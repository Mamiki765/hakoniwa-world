# 箱庭諸島２S＋マニュアル

箱庭諸島２S＋は、同じ世界の海に島を作り、2時間ごとのターンで開発するゲームです。人口、食料、資金のバランスを取りながら、施設や景観を育てます。災害、怪獣、他島からの攻撃も同じ世界で起こります。

## 読み進め方

- [初級編](/manual/beginner)：最初の開発、人口、食料、資源、生産
- [中級編](/manual/intermediate)：開発計画、一括操作、特殊施設、ミサイル、怪獣
- [上級編](/manual/advanced)：ターン順序、災害、上限、長期運営
- [交易場](/manual/trading-post)：出品、入札、預託資金、落札と保管上限
- [秘書について](/manual/secretary)：スキル、倉庫、装備、アイテムの効果
- [箱庭ダンジョン](/manual/underground)：探索、能力値、成長方針、Skill Tree、装備

ゲームの運営方針は[利用ルール](/community-guidelines)、使用素材などは[クレジット](/credits)で確認できます。

## まず覚えること

- 開発計画は上から順に実行されます。
- 食料は人口維持に必要です。余裕を持って備蓄してください。
- 農場へ先に人が割り当てられ、残った人が工場と採掘場で働きます。
- 施設は一か所に集めすぎず、災害で同時に失わない配置にします。
- 島の出来事ログには、成功、失敗、災害、攻撃結果が記録されます。

セル詳細に表示される海域名は、16×16セルごとの区域名です。地形の効果や所有権を変えるものではありません。
