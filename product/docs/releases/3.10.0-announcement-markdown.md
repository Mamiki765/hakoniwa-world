## 表示と編集

- 新規作成画面はMarkdownを初期選択。太字、見出し、箇条書き、取り消し線、リンクの書き方を表示し、改行も保持する。
- 編集画面に本文形式と保存前プレビューを追加。プレビューは保存せず、本文・形式を変更すると古いプレビューを消す。
- 既存記事はプレーンテキストのまま表示・編集する。`**` や `-` を含む旧本文を自動で装飾しない。形式は明示的に変更できる。
- APIは原文 `body` と `body_format`、描画用 `body_html` を返す。形式省略時の新規作成は従来どおりplain text、更新は現在の形式を保持する。
- 既存のLaravel / CommonMarkを使用し、表示とプレビューで同じrendererを使う。直接のHTMLを除去し、危険なURL schemeを無効化する。本文のHTML入力をそのままDOMへ渡さない。管理者判定・題名のplain text制約・本文20,000字上限は保持する。
