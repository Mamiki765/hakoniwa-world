# 5.2.0

application version は **5.2.0**。Ruleset は本番使用中の v36 を `N` とし、未公開の v37 を同じ `N+1` の1世代として使う。v36 の snapshot は変更しない。5.1.2 の main を基点に、次の変更を `release/5.2.0` へ統合する。

- #267: 遷都に成功したあと 84 ターンは次の遷都を実行時に拒否する。一覧では残りターンを返す。
- #261・#264（画面統合 #270）: 自国の船に海マスの目的地を即時指定する。六方向の進路と目的地は置き換え合い、解除・到着・閉塞で船種ごとの通常行動へ戻る。他国・匿名の地図には目的地を出さない。
- #262・#266（画面統合 #270）・#272: 海底工作船（v37）。1国1隻、視界内でだけ見える。工作船のいるマスでは、陸地からの距離を問わず海底基地・海底都市・海底消防署を通常の3倍の費用で建てられる。油田は対象外。画像参照を登録する。
- #263: v37 で海底基地を暴動の対象から外す。
- #269: 地底戦闘の連続再生中はラウンド合計で止めず、次の行動へ続ける。
- #260: 埋め立て・海の掘削・海底建設の距離判定を自国の陸地を起点に共通化する。前の計画で陸地ができる／消える場合を予測に反映し、実行時に失敗する計画（首都保護・怪獣占有など）は起点の予測に使わない。視界外の他国施設の所有は予測に使わない。一覧 API に `distance_reason_code` / `projected_distance_reason_code` を追加する。
- #273: 距離の画面。計画のあとでも遠いコマンドに「範囲外」の札とボタン下の1行を出す。「先読み」札を「条件外」に改め、隠すかどうかを資金不足と切り離す。「計画後」だけならダイアログを挟まない。

予約自体は予測で禁止しない。資金・災害は予測しない。

## 検証と適用境界

各 PR の Quality CI と Codex review の結果は各 PR を正本とする。release の最終 HEAD の Quality CI を本番反映前に確認する。

この記録は本番 deploy・DB 更新・backup 完了の証拠ではない。本番適用は確定 SHA と同期結果を照合し、既存の backup・preflight・通常 deploy 手順に従う。migration は #261（船の目的地列）・#267（最後の遷都ターン）・#262（v37 の公開）の3本。
